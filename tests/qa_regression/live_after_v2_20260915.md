## 执行与判分边界

- 使用既有私有会话和同源接口，参考答案及工具金标不传给模型。
- 多轮题复用组内会话，单句题独立会话；口语题发送前扫描完整点位目录，结构化工具题单独标识。
- 固定代理、策略和必要依赖哈希。版本改变即停止；模型不可用先等待，不空跑后续题。
- 请求前写独占 claim，逐题保存结果；传输状态不明确则停止，不自动重放。
- 有答案只记 pending_review，不能直接算通过。工具合同与最终答案忠实度分开审阅。
- 首次后台启动在任何题目 claim 之前退出，已只读证明没有题目请求；改用已验证的独立启动通道后成功执行。没有重放问答。
- 随后该批次在第 8 题期间退出：7 题结果完整，第 8 题只有用户持久化记录，无助手答案。已将全部 8 个 claimed ID 从续跑计划中排除；该中断题记 interrupted_unknown，不重发。剩余 1252 题改由 Windows 独立无窗口进程执行，不依附 SSH 连接，也未创建计划任务或服务。进度必须同时检查进程是否存活，不能只信旧 running 字段。
