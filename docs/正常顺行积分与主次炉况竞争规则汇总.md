## 一、统一公式

正常顺行的每个分项先计算：

`g_N(x, a) = max(0, min(1, 1 - abs(x) / a))`

再按权重汇总：

`S_normal = 100 * sum(g_N(x_i, a_i) * w_i) / sum(w_i)`

若最高异常分大于 `60`，正常分还会执行：

`S_normal = min(S_normal, 100 - max_abnormal_score)`

代码位置：[正常规则](D:/文件/服务器实际运行版V4/炉况规则引擎/rules/normal.py)、[统一评分器](D:/文件/服务器实际运行版V4/炉况规则引擎/engine/scorer.py)。

## 三、当前实际主次炉况竞争规则

1. 先分别计算七类异常分：低料线、边缘煤气流发展、边缘不足/中心过吹、管道行程、炉凉、炉热、料柱失稳。
2. `normal` 不参加异常候选排序。
3. 异常分 `>=45` 才进入主炉况候选集合。
4. 没有异常达到 `45` 时，主炉况回退为正常顺行，且没有次诊断。
5. 最高异常分处于 `45<=A1<60` 灰区时，如果正常分满足 `N>=A1+3`，主炉况为正常顺行、次炉况保留该最高异常。
6. 灰区内若正常未领先满 3 分，或最高异常分 `A1>=60`，最高异常仍为主炉况；强异常不能被正常覆盖。
7. 异常为主时，第二高异常必须 `>=55`，并且与主异常分差 `<10`，才成为次炉况；否则没有次诊断。

```text
A1 = 最高异常分
A2 = 第二高异常分
N  = 正常顺行分

if A1 < 45:
    主炉况 = 正常顺行
    次炉况 = 无
elif A1 < 60 and N >= A1 + 3:
    主炉况 = 正常顺行
    次炉况 = A1对应异常
else:
    主炉况 = A1对应异常
    if A2 >= 55 and A1 - A2 < 10:
        次炉况 = A2对应异常
    else:
        次炉况 = 无
```

实际实现位置：[Resolver.resolve](D:/文件/服务器实际运行版V4/炉况规则引擎/engine/resolver.py)。当前代码虽然声明了优先级列表，但并列分数没有真正按该列表二次消解；本次也没有引入“连续两个五分钟点确认”，因此它仍是单点竞争规则。
