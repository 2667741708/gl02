# 二、统一公式与变量口径

公式点位标注说明：本版公式中的自动评分输入，均限定为《点位表格.xlsx》中可获取的实时传感器点位，或由这些点位计算得到的派生特征；未接入的化验、人工观察、炉前记录和安全联锁项不进入自动评分，只作为复核与处置建议。

所有分数统一为0-100。数值越高表示风险、异常或偏离越强；维护分则采用100-风险分的方式，数值越高表示状态越稳。

# 十、正常炉况运行维护操作建议（根据实际炉况）

本节用于补充炉长、工长在正常顺行或轻微波动状态下的日常维护建议。它不是专项事故处置清单，主要服务于平台在“正常炉况运行维护与优化”模块中，根据当前实际炉况、趋势变化和关键指标自动给出可复核、可执行的操作建议。

使用口径：当炉况处于正常顺行、轻微偏热、轻微偏凉、透气性轻微变化、煤气利用轻微波动等状态时，系统优先输出下列维护建议；当出现悬料、崩料、管道、烧穿、低料线事故等硬触发时，应转入专项炉况报警处理模块。
