# IMES 逐对象完整真实记录取样（2026-07-27）

## 需求

`Q-IMES-COMPLETE-ROW-SAMPLES-20260727`：使用当前两个 Vastbase
只读账号，盘点实际具备 `SELECT` 权限的 IMES 表/视图，并从每个对象
抽取一条真实记录，完整保留数据库返回的全部列和 `NULL`。

## 查询边界

- 链路：本机 `127.0.0.1:15433` 经 220.12 只读转发至 Vastbase。
- 查询账号：生产作业只读账号和实验室视图只读账号。
- 数据库会话返回 `transaction_read_only=on`。
- 对每个对象执行一条 `SELECT * ... LIMIT 1`；大表
  `public.batch_input` 额外使用 `2026-07-26` 至 `2026-07-27`
  的业务日期条件，避免无条件扫描超时；旧炉渣视图
  `public.slag_inspection` 使用 `meltno IS NOT NULL`，避免抽到全字段
  均为空的占位行。
- 样本只用于展示字段结构和真实值，不代表“最新一条”“典型值”或
  完整数据质量结论。
- 通用文档不记录密码；用户于 2026-07-27 明确要求后，完整记录报告通过
  `--include-plaintext-credentials` 写入两个数据库账号用途、用户名和
  明文密码。该报告已加入 `.gitignore`，不得提交、截图外发或复制到前端。

## 多账号 MCP 访问方法

MCP 服务为
`高炉前端数据/智能助手/mcp/imes_relay_mcp_server.py`，现支持：

- `operations`：炉次作业、生产实绩、批次投料、铁水旧化验和炉渣旧检验；
- `laboratory`：铁水、原料/烧结矿、炉渣和炼钢最终化验视图；
- `list_imes_database_profiles`：查看账号用途，不返回密码；
- `list_imes_business_objects(account_profile)`：查看所选账号全部可读对象及列；
- `query_imes_variables`：按对象、具体列、时间字段、左闭右开时间窗和精确条件查询；
- `query_imes_readonly_sql`：使用 `%s` 参数执行任意单条只读 SQL。

完整可复制的 MCP JSON 参数已经写入本机敏感报告
`logs/imes_complete_row_samples_20260727/imes_complete_row_samples.md`。
真实冒烟入口为 `tools/smoke_test_imes_multi_account_mcp.py`，结果写入
`logs/imes_multi_account_mcp_smoke_20260727.json`。

任意查询仍有三层边界：数据库账号自身 `SELECT` 权限、数据库只读事务、
单条只读 SQL 校验。结构化目录默认发现 `public` schema；如果未来另行
授权业务 schema，可通过 `IMES_MCP_DISCOVERY_SCHEMAS` 显式登记。

## IMES Web 的区别

`pes_bin`、`pes_bin_material`、`dosing_scheme`、`input` 等属于 IMES Web
白名单接口数据集，不在上述两个数据库账号实际可读的 11 个表/视图中。
2026-07-27 Web 转发本身可达，但当前浏览器会话停留在登录页，
未持有有效登录会话，因此本次报告没有用示例数据冒充这四类 Web 真实记录。
获取它们需要授权用户先完成 IMES Web 登录和验证码，再调用
`tools/export_imes_web_readonly.py`。
