# ADR-20260806：建议页采用可视驾驶舱、证据中心和只读抽屉

## 状态

已接受。

## 背景

8炉况矩阵、完整动作审计和模型复核同时进入固定高度主流程后，1366×768 下驾驶舱顶部被压到0px，原有数字与曲线不可见。用户同时要求在4项炉况主证据之外查看固定19项核心变量及曲线。

## 决策

1. 页面采用单一纵向滚动；驾驶舱和历史图使用内容驱动高度，不再共享固定 `1fr + 270px` 高度预算。
2. 8种炉况使用紧凑切换条；完整2×4矩阵按需展开。
3. 所选炉况始终保留4项规则主证据；固定19项核心证据中心默认折叠并延迟挂载图表。
4. 完整动作审计和模型证据进入右侧只读抽屉，主流程只保留状态计数和复核摘要。
5. 当前主炉况可以自动模型复核；假设炉况只在人工请求时复核，避免一次诊断触发8次模型调用。
6. 8093/8094页面共享8768；纯前端更新不重启8093、8094或8768，并以PID不变作为发布门禁。

## 后果

- 优点：恢复原页面的数字/曲线可读性；证据范围扩大而不淹没首屏；动作字段保持完整；模型成本可控。
- 代价：展开19项后页面明显变长，因此必须保留内部滚动、分类筛选和延迟图表挂载。
