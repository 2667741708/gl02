# GL02软熔带上移综合趋势经验规则

追踪编号：`REQ-HCZ-UPWARD-EXPERT-RULE-20260810`  
规则编号：`HCZ-UP-FOREMAN-001`  
适用高炉：GL02  
生效日期：2026-08-10

## 1. 判定结论

本规则把高炉长经验固化为一个严格的综合趋势判断。只有数据覆盖合格，并且核心趋势、炉壁温度和持续时间三个门全部通过时，才输出“软熔带上移综合趋势规则已触发”。任一条件未达到即输出“未触发”；覆盖不足时输出“数据不足”，不得用0补数。

该结论是`expert_rule_indication`（专家经验规则指示），不是软熔带高度的直接测量真值，不是经过真实HCZ标签标定的模型结果，禁止自动控制。

## 2. 时间窗和比较基准

- 先把分钟实测聚合为小时均值；评价时刻向下取整到完整小时。
- 当前窗为最近24个小时；基准窗为当前窗之前连续5天，共120个小时，两窗不重叠。
- 核心变量每小时至少30个分钟样本；当前窗至少18个有效小时，基准窗至少96个有效小时。
- 炉壁测点允许稀疏刷新：每层每小时至少4个方位有值；同样要求当前18/24、基准96/120有效小时。

记当前24小时均值为`mean24(x)`，前5天均值为`mean5d(x)`，变化量为`Δx = mean24(x) - mean5d(x)`。

## 3. 核心综合趋势

下列五项必须同时满足：

| 指标 | 实测变量 | 判据 |
|---|---|---|
| 平均顶温 | 优先`T_top`，现场实际使用`T_top_A~D`有效点平均 | `ΔT_top >= +15 ℃` |
| 全压差 | `DP_total` | `ΔDP_total >= +5 kPa` |
| 透气性指数 | `PI` | `ΔPI <= -0.5 m³/(min·kPa)` |
| 煤气利用率 | `GasUtil` | `ΔGasUtil <= -1.0个百分点` |
| 冷风风压 | `P_blast_cold` | `ΔP_blast_cold >= +5 kPa` |

“煤气下降1%”按煤气利用率下降1个百分点固化，避免把相对百分比和百分点混用。

## 4. 炉壁温度门

- 使用7～13层，每层汇总A～H八个方位的有效点。
- 至少2层的`当前24小时均值 - 前5天均值 >= 10 ℃`，炉壁温度门通过。
- 若至少3层上升10℃，且其中至少1层上升20℃，只把证据强度标为`strong`；这不是额外的触发必要条件。

## 5. 连续12小时门

在当前24小时内逐小时比较。某一小时只有同时满足五项核心阈值，并有至少2个炉壁层较各自前5天均值上升10℃，才算一个合格小时。连续合格小时的最大长度必须至少12小时。缺数小时直接判为不合格并中断连续计数。

最终公式为：

```text
soft_zone_upward = data_sufficient
                   AND all_5_current_24h_trends_pass
                   AND rising_body_layers_10C >= 2
                   AND max_consecutive_qualified_hours >= 12
```

## 6. 状态解释

| 状态 | 含义 |
|---|---|
| `triggered` | 完整经验组合达到，提示人工复核软熔带上移 |
| `not_triggered` | 数据足够，但至少一个规则门未通过；不等于证明软熔带稳定或下移 |
| `insufficient_data` | 数据覆盖不足，暂不能判断 |

触发后也必须由高炉长结合炉料、风口、出铁、渣铁温度、炉况事件及人工HCZ弱标签复核；规则页面不提供生产设定值写入。

## 8. 2026-08-11煤气利用率单位修复

220.12的`GasUtil`实际存储为0～1比例值。`BUG-HCZ-GASUTIL-UNIT-20260811`已在2026-08-11修复并部署：API读取后统一乘100一次，规则引擎按0～100数值计算“百分点”差值。页面当前值和前5天基线显示`%`，变化量及阈值显示“个百分点”。禁止在规则引擎或浏览器再次乘100。

生产现场复验值约为当前`45.83%`、前5天`46.38%`、变化`-0.55个百分点`。三个月单位校正回放仍未出现完整上移事件。历史发现过程见[三个月历史核对](./HCZ软熔带上下移动三个月历史核对_20260811.md)。

## 9. 经验阈值历史敏感性试算

8093页面允许高炉长临时调整八项经验阈值，并选择最近7、30或90天真实数据回放。系统同时计算生产默认阈值和本次试算阈值的上移事件、命中小时及符号对称下移候选，便于判断单项阈值变化是否真正改变完整综合诊断量。

试算固定为只读：输入值不写数据库、不修改YAML、不替换生产默认阈值，也不触发自动控制。下移只是把方向判据镜像后的研究候选，并非高炉长已经确认的下移生产公式。

2026-08-11生产近90天回放中，把平均顶温阈值从`15℃`降到`10℃`，完整上移事件为`0→0`，对称下移候选事件为`0→0`。这只说明其他AND条件和连续12小时门仍限制完整事件量，不能解释为平均顶温单项没有变化。
