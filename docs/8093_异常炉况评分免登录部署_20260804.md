# 8093 异常炉况评分免登录部署

需求编号：`REQ-8093-DIAGNOSIS-REVIEW-NO-LOGIN-PRODUCTION-20260804`

## 已上线范围

2026-08-04 已将异常炉况居中弹窗、三态复核、可选0～100人工匹配分、可选建议，以及诊断页八张炉况卡的手动评分入口部署到 `http://10.30.220.12:8093/`。

8093 不再要求先以高炉长账号登录才可评分。浏览器不能提交评分人姓名或角色；服务端在无有效授权会话时固定记录：

- `reviewer_username=onsite_8093`
- `reviewer_role=现场高炉长`
- `identity_mode=onsite_anonymous`

“现场匿名”仅表示不绑定个人登录账号；事件仍保存诊断时间、提交时间、来源页面、服务端诊断快照、系统八类分、人工分/建议和幂等键。若浏览器已有允许角色的有效签名会话，仍保留实名 `signed_session` 身份。

本次只修改并重启 `BFV4PreviewProxy8093`。`BFV4PreviewWs8768`、8094服务、Ollama和数据库服务均未停止或修改；部署前后8768和8094监听PID不变，8094页面内容SHA-256不变。

## API和权限边界

- `GET /api/diagnosis-review-context`：免登录读取当前服务端诊断快照和提交能力；8093返回 `login_required=false`、`can_submit=true`。
- `POST /api/diagnosis-reviews`：免登录提交异常弹窗三态复核、可选人工分和建议。
- `POST /api/diagnosis-manual-scores`：免登录提交任一炉况卡的人工分或建议。
- `GET /api/diagnosis-reviews`、`GET /api/diagnosis-manual-scores`：仍要求允许角色登录，未扩大历史事件读取权限。
- `/api/auth/*` 和其他后台接口保持原权限。

两类POST请求只接收人工判断和快照标识。诊断时间、主诊断、证据、数据覆盖率与八类系统分由服务端重新读取 `bf_sensor.diagnosis_snapshots`；浏览器传入的分数或身份不会覆盖服务端快照。

## 数据库和配置

事件保存到220.12本机PostgreSQL 16.13：`127.0.0.1:5432/bf_trend`。

- 异常弹窗：`bf_assistant.diagnosis_review_events`
- 手动评分：`bf_assistant.diagnosis_manual_score_events`

8093服务配置启用以下非密钥变量：

```text
BF_DIAGNOSIS_REVIEW_ENABLED=1
BF_DIAGNOSIS_REVIEW_TEST_MODE=0
BF_DIAG_REVIEW_REQUIRE_LOGIN=0
BF_DIAG_REVIEW_ANONYMOUS_USERNAME=onsite_8093
BF_DIAG_REVIEW_ANONYMOUS_ROLE=现场高炉长
BF_DIAG_REVIEW_PGHOST=127.0.0.1
BF_DIAG_REVIEW_PGPORT=5432
BF_DIAG_REVIEW_PGDATABASE=bf_trend
BF_DIAG_REVIEW_PGUSER=gl02_sync
BF_DIAG_REVIEW_PGPASSWORD_ENV=GL02_PGPASSWORD
BF_DIAG_REVIEW_PGSCHEMA=bf_assistant
```

密码仍来自220.12机器环境，不写入新脚本、前端或本说明。数据库目标不是回环地址时后端拒绝启动复核存储。

本地8890“炉况数据仪表盘”的“高炉长评分”页签已具备查询和导出合同，但它只读取自身配置指向的复核库。若8890仍连接本机 `127.0.0.1:18000`，不会自动显示220.12的新记录；需要通过批准的回环隧道把其 `BF_DIAG_REVIEW_PG*` 指向220.12事件库。本次8093部署没有修改8890运行配置。
