# GL02 高炉 3D 传感器点位清单索引

本文件只负责在项目根 `docs/` 中提供稳定入口，不复制 133 点正文，避免出现两份点表
分别修改后失去一致性。

权威文件位于 `PT/高炉3D模型/docs/`：

- [人读点位清单](../PT/高炉3D模型/docs/GL02传感器点位清单.md)
- [133 点机器清单](../PT/高炉3D模型/docs/GL02传感器点位清单.v1.json)
- [独立单位映射](../PT/高炉3D模型/docs/GL02传感器单位映射.v1.json)
- [独立炉层与工艺语义映射](../PT/高炉3D模型/docs/GL02传感器语义映射.v1.json)
- [GL02 综合数据映射合同](../PT/高炉3D模型/docs/GL02数据映射附件.md)

生成入口：

```powershell
python tools\build_gl02_bf3d_sensor_catalog.py
```

生成程序以 `bf_sensor.sensor_registry` 中 `is_enabled=true` 且非派生的物理点为
数据库身份来源，并校验其与 133 点 Billboard 集合完全一致。数据库当前没有
`unit` 字段，所以单位由独立单位映射文件维护；数据库中文名和 `description` 原文
始终保留在点位清单中。
