## 本小时喷煤量算法

设喷煤实际速率为 `r(t)`，单位 `t/h`，本小时起点为 `H=date_trunc('hour', 当前时刻)`：

`本小时喷煤量(t) = ∫[H, 当前数据时刻] r(t) dt / 3600`

页面接收的 8770 数据可能每数秒一帧，8768 历史通常每分钟一帧，因此必须使用相邻样本的实际毫秒差积分，禁止按“每收到一个样本就除以60”累加。任一无数据间隔超过150秒时，只计前150秒，不把旧速率无限外推到缺测区间。

例如 `11:00–11:19` 的平均速率始终为 `41.37 t/h`，计算结果为 `41.37 × 19 ÷ 60 = 13.1005 t`。`41.37` 是速率，不能直接显示为本小时吨数。

## PostgreSQL 记录

- 新表：`bf_sensor.coal_injection_hourly`，一小时一行。
- `metered_amount_t`：下一小时内 `PCI_previous_hour` 的中位数，对应上一完整小时的生产累计值。
- `integrated_amount_t`：该小时 `PCI_rate` 分钟均值按 `interval_seconds/3600` 积分。
- `average_rate_tph`：该小时平均喷煤速率。
- `coverage_ratio`：已覆盖秒数除以3600；缺测不补零。
- 视图：`bf_sensor.v_coal_injection_hourly`、`bf_sensor.v_coal_injection_current_hour`。
- 完整小时展示优先使用 `metered_amount_t`，没有实测累计时才回退 `integrated_amount_t`；当前未结束小时只使用积分值。
