# 软熔带上升/下降趋势计算与升级分析

日期：2026-08-08  
问题编号：`Q-COHESIVE-ZONE-TREND-CALCULATION-20260808`  
当前模型：`C2-ROOT-BASELINE-2026.07`

## 1. 结论

当前项目已经实现一套可解释的低置信度基线。它预测的不是炉内真实软熔带
边界，而是“炉墙侧热活动根部代理”的上移、下移或稳定状态。

当前计算适合在线显示短时方向、检查温度/压力是否共同变化，以及形成专家标注
和历史回放的初始弱标签；不适合直接用于自动控制，也不能把输出标高称为真实
1000℃等温面。

建议采用两层结构：第一层继续用可解释状态估计器计算当前根部代理；第二层在
连续状态持久化、时间语义统一和专家/物理标签就绪后，预测未来
15/30/60分钟的高度变化和方向概率。

## 2. 当前基线如何计算

设评价时刻为`t0`：

```text
参考窗口：t0-45min ～ t0-30min
隔离窗口：t0-30min ～ t0-15min
当前窗口：t0-15min ～ t0
```

两个有效窗口的中心相隔0.5小时。

### 2.1 数据门禁

- 使用L7～L13、A～H共56个炉体温度点；
- 每点每窗口至少5个有效一分钟样本；
- 每层至少4个当前/参考共同方位，至少5个共同层；
- 核心温度、压力和透气性最新值不超过5分钟；
- 只读取`t0`及以前的数据，不允许未来填充或`bfill`。

当前和参考窗口必须用相同的`(层, 方位)`支撑，避免缺测结构变化被误判为
软熔带移动。

### 2.2 炉墙热活动中心

每层先对共同方位取中位数，得到层温`T_i`和层高`h_i`：

```text
T_norm_i = clamp((T_i-min(T))/max(max(T)-min(T),1℃),0,1)
w_i      = 0.10 + T_norm_i^1.60
H_temp   = Σ(h_i×w_i)/Σw_i
```

分别得到当前中心`H_temp_current`和参考中心`H_reference`。

### 2.3 热输入小幅修正

对`Q_blast/T_blast/Q_O2/O2_rate/PCI/TFT`分别计算当前窗口相对参考窗口的
归一化变化：

```text
delta_j = clamp((current_j-reference_j)/scale_j,-1,1) × direction_j
thermal_index = weighted_mean(delta_j)
H_current = clamp(H_temp_current + 0.35×thermal_index,15.0,28.5)
```

热输入最多只修正0.35m，不允许压过温度高度剖面。

### 2.4 上移、下移和15分钟外推

```text
v = clamp((H_current-H_reference)/0.5h,-2.40,+2.40) m/h

v > +0.12m/h  => up
v < -0.12m/h  => down
其他          => stable

H_15 = clamp(H_current + v×15/60,15.0,28.5)
```

这表示两个历史窗口之间的代理状态变化率，不是炉料颗粒运动速度。

### 2.5 厚度代理

`DP_total/DP_lower/DP_upper/PI`和三高度静压力纵向梯度先形成阻力指数
`R_pressure∈[-1,1]`，其中PI方向与压差相反。

```text
thickness = clamp(
  2.10 + 0.85×R_pressure
  + 0.08×(temperature_height_spread-3.50),
  1.20,4.50
)
```

这是阻力与温度高度分布的有界代理，不是真实矿层厚度。

### 2.6 周向偏心

每层温度和每个静压力标高先减去本层/本标高均值，再计算一阶圆周谐波：

```text
ecc_vector = 0.82×temperature_vector + 0.18×static_pressure_vector
eccentricity = clamp(|ecc_vector|,0,1)×0.75m
H_sector = H_current + eccentricity×cos(theta_sector-eccentric_angle)
lower = H_sector-thickness/2
upper = H_sector+thickness/2
```

A点绝对厂区方位尚未确认，所以只能输出相对A～H方位。

### 2.7 置信度

输入组权重为炉体温度0.65、压力/透气性0.25、热力输入0.10。置信度还会
乘以共同层、共同方位等覆盖因子，最终固定不超过0.45；不确定包络限制为
0.55～1.80m。

## 3. 算例

以下只是公式演示，不代表当前炉况：

```text
H_temp_current = 21.40m
H_reference    = 21.25m
thermal_index  = 0.20

H_current = 21.40 + 0.35×0.20 = 21.47m
v         = (21.47-21.25)/0.5 = +0.44m/h
方向      = up
H_15      = 21.47 + 0.44×0.25 = 21.58m
```

若`R_pressure=0.30`、温度高度离散宽度为3.80m：

```text
thickness = 2.10 + 0.85×0.30 + 0.08×(3.80-3.50)
          = 2.379m ≈ 2.38m
```

## 4. 当前算法的主要局限

1. 当前只是双窗口差分。15分钟常速外推不会识别加速、转向、周期波动或
   滞后响应。
2. 热力修正不对称。当前中心叠加热力修正，参考中心不叠加相同修正，容易把
   热输入突变解释成已经发生的位置移动。
3. 温度层内min-max会丢失绝对变化。全体层温同步上升时相对形状可能不变；
   剖面很平坦时也仍可能给出几何中心。
4. 压力主要影响厚度，没有充分参与根部高度。下一版应以三标高两段压降形成
   独立的阻力中心标高，再与温度中心按质量加权融合。
5. 根部高度、厚度和偏心依赖的数据不同，不应长期共用一个置信度。建议分别
   输出`confidence_height/thickness/eccentricity/forecast`。
6. `bf_sensor.one_minute_values`在2026-08-05 21:55前主要是分钟末有效raw
   样本，之后才是同分钟全部有效Good raw的算术平均。跨期训练前必须统一
   语义或分段审计，不能把采样口径变化当成炉况变化。

## 5. 推荐的生产升级计算

### 5.1 第一层：稳健当前状态估计

构造状态：

```text
x_t = [root_height,velocity,thickness,eccentric_x,eccentric_y]
```

观测包括：

- 基于30天层/方位基线标准化后的温度中心；
- 三标高分段压降重心；
- `DP_upper/DP_lower/DP_total/PI`阻力分配；
- A～H温度和A～F静压力一阶圆周模态；
- 冷却水换热功率相对变化。

先用稳健指数平滑或卡尔曼状态空间模型融合，按数据新鲜度和覆盖率动态调整
观测权重。连续状态按一分钟持久化，不能只保存最新快照。

### 5.2 第二层：未来趋势预测

预测目标建议定义为：

```text
ΔH_15 = H(t+15min)-H(t)
ΔH_30 = H(t+30min)-H(t)
ΔH_60 = H(t+60min)-H(t)
```

方向由预测分布产生：

```text
P(ΔH > +deadband) => 上移概率
P(ΔH < -deadband) => 下移概率
其余               => 稳定概率
```

没有真值时优先使用有物理约束的状态空间模型和稳健斜率，不建议直接训练深度
网络去拟合当前启发式伪标签。取得专家弱标签或探针真值后，再比较LightGBM、
TCN/Transformer与状态空间基线。

### 5.3 预测特征及合理时延

- 0～60分钟：温度层剖面、温度斜率、DP/PI、三层静压力、顶温/顶压；
- 30～240分钟：风量、风温、富氧、喷煤、TFT、煤气利用率；
- 1～6小时候选：矿焦批、矿焦比、布料矩阵、料线速度和滑料/悬料事件；
- 炉次后验：铁水Si/S、炉渣FeO/R2等只用于回看校验和漂移监测。

各时延应以时间阻塞回放、互相关和专家核验共同冻结。铁水Si是滞后结果，不能
作为当前软熔带在线位置的同时刻输入。

## 6. 验收指标

- 上移/下移/稳定的宏平均F1、平衡准确率；
- 方向概率Brier分数和可靠性曲线；
- 趋势持续性、每小时翻转次数和异常跳变率；
- 15/30/60分钟预测区间覆盖率；
- 各输入组缺失/陈旧率；
- 按炉次、班次、月份和不同料制分层的稳定性；
- 全流程未来数据泄漏为0。

有探针或专家高度标签后，再增加根部高度MAE、厚度MAE和偏心角误差。数据集
必须按时间阻塞切分，并对重叠窗口设置purge/embargo；不得随机打乱一分钟样本。
