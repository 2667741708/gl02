# 软熔带上升/下降趋势预测数据源只读核查

核查时间：2026-07-19  
追踪编号：`Q-COHESIVE-ZONE-DATA-SOURCES-20260719`  
范围：2# 高炉 pSpace 与一期 IMES Vastbase；只读，不修改生产数据。

## 1. 结论

当前数据源已经足以建设“软熔带炉墙侧根部上升/下降趋势”的下一版输入层，
但还不足以宣称获得真实软熔带位置或完成生产标定。

本次最重要的结论是：

1. L7～L13 炉体温度、18 个 A～F 静压力点、压差/透气性、风/氧/煤、
   顶温/顶压和料线均可从 pSpace 实际读取。
2. pSpace 中还存在此前未纳入状态表的冷却壁供回水、上下分区流量、
   实测/目标溜槽角度、旋转角、布料圈数、料批号、批重和下料闸开度。
   这些不是“数据源缺失”，而是“尚未完成语义对表、历史入库和模型接入”。
3. IMES 可读取批次投料、炉次作业、生产实绩、铁水化验、炉渣化验和烧结矿化验；
   但命名化验视图与六个业务原表由两套只读身份分别可见，不能假设单一账号能读全。
4. `t_ipes_cond.tappingtemp` 字段存在，但 2# 高炉当前可见的 9,373 条历史炉次记录
   中非空数为 0；它不能作为“铁水温度已有数据”。当前 pSpace 的铁口温度也只是代理量，
   不能替代铁水实测温度。
5. 当前未检出径向 CO/CO₂/H₂ 或十字测温煤气成分点；烧结矿化验可查，
   但球团、块矿完整物性、粒度和软熔滴落试验参数仍未贯通。

## 5. 建议的接入顺序

1. 先接入已明确的实时强信号：56 个 L7～L13 温度、18 个静压力、
   `DP/PI`、风/氧/煤、顶温/顶压和主料线。
2. 将 pSpace 冷却壁总回路和上下分区流量纳入模型，但第一版只计算
   “总回路换热功率/相对变化”，不输出局部热流密度。
3. 建立 `pSpace 批号/批重/溜槽/闸门事件 -> IMES lot/charge/workdate2`
   的事件对齐表，再生成实际入炉时刻和布料特征。
4. 化验特征必须按 `published_at` 延迟进入回放；铁水温度在取得非空真值源前保持缺失。
5. 申请或定位径向煤气分析数据和完整炉料物性；在此之前模型继续标记
   `estimated + uncalibrated + control_use=prohibited`。
