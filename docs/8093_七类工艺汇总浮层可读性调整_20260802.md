# 8093 七类工艺汇总浮层可读性调整（2026-08-02）

需求编号：`REQ-BF3D-8093-FURNACE-SUMMARY-READABILITY-20260802`

## 1. 调整对象

本次只调整 8093 总览 3D 高炉四周的 7 张外围工艺汇总浮层：

1. 煤气顶压
2. 压差透气
3. 喷煤
4. 料线
5. 热制度
6. 送风供氧
7. 出铁口温度

这些浮层是汇总多个工艺变量的 HTML 卡片，不是炉壳上的 121 个中文 Billboard 点位。

## 2. 原因与现象

旧样式在页面高度不超过 `760px` 时把每张卡片固定压缩为 `116px`。卡片内部仍需要同时容纳字段名、实时数值和单位，并为三列设置了 `overflow:hidden` 与 `text-overflow:ellipsis`，因此“综合顶压”“理论燃烧温度”等内容会变成不可恢复的“综…”或“理…”。

该问题属于响应式压缩引起的文本截断，不是 WebGL 深度遮挡，也不是 Billboard 悬停抖动。

## 3. 实现

专用样式文件：

- [bf3d-furnace-summary-readability-8093.css](../高炉前端数据/assets/bf3d-furnace-summary-readability-8093.css)

尺寸口径：

| 断点 | 卡片宽度 | 行文字 | 单位 |
|---|---:|---:|---|
| 常规桌面 | `208–228px` | `13px` | 显示 |
| 宽桌面（≥1500px） | `220–242px` | `13.5px` | 显示 |
| 紧凑桌面或高度≤760px | `198px` | `11.5px` | 显示 |
| 高度≤680px | `190px` | `10.5px` | 显示 |

三列改为“字段名弹性列＋数值自然宽度＋单位自然宽度”，并取消不可恢复的省略号。原跟随模型定位程序会在每帧读取卡片真实 `offsetWidth/offsetHeight`，所以宽高变化会自动纳入左右定位、垂直避让和引线终点计算，无需重写 3D 锚点算法。

## 4. 隔离边界

- 不选择 `.furnace-billboard`，121 个物理测点 Billboard 的 `1.22×` 醒目度保持不变。
- 不选择 `.core-group-row`，左侧 28 变量面板的尺寸、顺序和布局保持不变。
- 不改相机、炉壳防穿透、悬停迟滞和 WebSocket 数据逻辑。
- 只在 8093 页面加载该样式，8094 不加载。
- 部署器对 8094 HTML、共享 Billboard adapter 和 8094 相机资源执行部署前后 SHA-256 保护。
