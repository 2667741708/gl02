# 调控结论生成引擎可追踪说明

本文档记录完整建议引擎从需求契约到代码、8767 payload、前端展示和验证脚本的追踪关系。后续修改动作模板、严重度、安全门禁、8767 字段或前端优化建议页时，必须同步更新本文、`docs/automation_traceability.md` 和对应测试。

## 需求 ID

`REQ-OPT-FULL-ENGINE-20260715`

目标：恢复完整调控结论生成模块，让 8767 在每个最新诊断快照上生成标准 `recommendation`；前端只消费后端结构化结果，不再自行拼造 `100%/34%` 这类固定分数或静态建议。

## 当前结论

已落地的独立代码目录名为 `调控结论生成引擎`，不是 `suggestionengine`。如果后续需要英文别名，应只作为文档别名或环境变量说明，不另建第二套漂移实现。

## 8767 接入

8767 WebSocket 桥接通过 [recommendation_adapter.py](../自动诊断服务/recommendation_adapter.py) 适配数据库诊断快照和当前值：

- 默认引擎目录：`PROJECT_ROOT / "调控结论生成引擎"`。
- 可选覆盖变量：`BF_RECOMMENDATION_ENGINE_DIR`。
- 引擎版本：`v4-complete`。
- 输出元数据：`engine_meta.name=blast_furnace_recommendation_engine`、`engine_meta.source=diagnosis_snapshot`、`engine_meta.read_only=true`。

[local_pg_ws_bridge.py](../自动诊断服务/local_pg_ws_bridge.py) 在生成诊断 payload 时调用 `generate_recommendation(payload, current_values)`，成功时写入：

```json
{
  "recommendation_status": {
    "state": "ready",
    "engine": "blast_furnace_recommendation_engine",
    "version": "v4-complete"
  },
  "recommendation": {
    "goal": "...",
    "immediate_actions": [],
    "followup_actions": [],
    "forbidden_actions": [],
    "observe_items": [],
    "safety_gate_passed": true,
    "safety_warnings": [],
    "engine_meta": {
      "read_only": true
    }
  }
}
```

失败时 8767 不伪造建议，而是移除 `recommendation` 并写入 `recommendation_status.state=failed` 和 `error_type`，供前端显示错误或降级状态。

## 前端绑定边界

[frontend_dashboard_v3.server.html](../高炉前端数据/frontend_dashboard_v3.server.html) 的优化建议页应读取 `diagnosis.recommendation` 与 `recommendation_status`。前端允许做展示排序、中文格式化、置信度归一化和空/错态提示，但不得自行发明动作分数、风险贡献或替代后端标准建议。

前端契约信号：

- 文件包含 `REQ-OPT-FULL-ENGINE-20260715`。
- 优化建议页绑定 `OptimizationTab=OptimizationEngineCockpitLayout;`。
- 置信度通过 `bfRecommendationConfidence()` 归一化。
- 组件内不得再使用旧 `a.score` 作为动作分数，也不得显示“风险贡献”。
- 当前炉况卡同时显示 `diagnosis_ts` 与传感器最新时间；诊断按5分钟档位落库，传感器按1分钟更新，两者不能混作同一更新时间。

## 安全边界

引擎只生成只读建议，不连接、不调用、不暴露任何生产控制写接口。所有强动作必须由现场制度和值班长/高炉长确认。

固定安全门禁包括：

- 高压运行：禁止直接放风坐料或休风，必要时先改常压。
- 悬料征兆：先解除悬料再考虑休风，并复核探尺、风压、压差和透气性。
- 顶温超限：顶温超过 350 摄氏度时安全门禁不通过，优先控顶温和减风。
- 风口异常：严禁强行恢复风量，优先检查风口防灌渣。
- 管道或悬料伴随 TRT 运行：先解列 TRT。

## 修改清单要求

后续变更必须同步检查：

1. 修改动作或门禁：更新 `调控结论生成引擎/recommendation/*`、本文、PT 说明和验证脚本。
2. 修改 8767 字段：更新 `recommendation_adapter.py`、`local_pg_ws_bridge.py`、前端读取逻辑、测试和 API/追踪文档。
3. 修改前端展示：保留后端 recommendation 为唯一建议来源，补充浏览器验收截图或说明未跑浏览器的原因。
4. 修改安全门禁：必须确认只读边界不变，不能新增生产控制写入。
