## 1. 为什么单独增加这轮

此前扩展矩阵把问题写成“顶压（P_top）”等形式，能验证工具和参数，却不能证明模型可以只凭现场
口语找到唯一点位。本轮新建 42 个不含任何内部点位 ID 的问题，分别询问当前值、一小时稳定性和
两小时升降趋势。A-H 仅作为独立物理方位字母，例如“顶温 A 点”；`T_top_A` 不属于口语。

## 3. 六个失败的含义

### T_top：要求平均值，回答成四个分点

“四个顶温的平均值”三题都被解析成 `T_top_A/T_top_B/T_top_C/T_top_D`。工具返回真实数据且速度
正常，但答案没有给出用户要求的派生平均，所以按最终答案忠实度判失败。底层 MCP 已支持 `T_top`
派生对象，后续应修 QA 口语优先级，而不是让模型临时心算。

### L：能找到雷达探尺，但没有稳定进入确定性路径

三题最终都找到标准对象 `L`，但先进入模型规划：最新值用了 2 个工具，一小时统计 1 个工具，两小时
趋势 3 个工具。耗时约 `32999.9ms / 75943.7ms / 29513.7ms`。答案把料线单位写成“未登记”或
“无量纲”，不能满足单位忠实度，因而不能算通过。

## 4. 建议的最小修复

1. 把“四个顶温的平均值/四点顶温平均”等表达优先映射到 `T_top`，只有明确询问 A-D 分点时才展开。
2. 把“雷达探尺/雷达料线/主料线”加入 `L` 的确定性口语别名。
3. 在权威点位元数据中登记经现场确认的 `L` 单位；确认前继续显示“单位未登记”，不能猜成 `m`。
4. 修复后只真实重跑这 6 题，每题一次；其余 36 个通过题不重复消耗模型。
