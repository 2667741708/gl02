# 本机 8093 移除三维控制与炉内仿真

需求编号：`REQ-BF3D-8093-REMOVE-SIMULATION-CONTROLS-20260806`

## 用户目标

从本机 8093 主页面移除：

- “炉体 / 测温层 / 剖面 / 审查”底部控制区；
- 炉内仿真与工艺对象运行时；
