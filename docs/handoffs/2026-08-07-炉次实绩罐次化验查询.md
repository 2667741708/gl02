# 炉次实绩罐次化验查询改造

需求标识：`REQ-8093-HEAT-PERFORMANCE-QUALITY-QUERY-20260807`

## 目标

8093“炉次实际/炉次生产实绩”继续显示炉次汇总和 Si 事实，同时允许按炉次号、试样号、罐号关键词和日期查询；点击炉次后查看该炉次已返回的每个出铁段（或罐次）以及每个原始试样的 C/Si/Mn/P/S 化验结果。

## 数据与语义

- 数据源仍是只读的 `heat_performance_quality_summary` 镜像；每个 `meltno` 一行，`sample_details` 保存多个化验样本，`output_details` 保存多个出铁/称量段。
- 如果源端没有返回罐号字段，页面明确显示“罐号未提供”，只展示出铁段序号和样本序号，不把样本强行绑定到某一罐。这样不会把样本顺序误当成罐号。
- `work_date` 日期过滤为闭区间；“仅显示已有化验”只过滤 `sample_details` 非空的炉次。

## API

只读入口：

```text
GET /api/heat-performance-quality?limit=100&q=<炉次/试样/罐号>&date_from=YYYY-MM-DD&date_to=YYYY-MM-DD&has_samples=1
```

响应保留 `sample_details` 与 `output_details` 数组，并在顶层返回 `filters`，便于前端显示当前查询条件。日期格式错误返回 HTTP 400；数据库不可用返回只读错误，不执行写入。

- `tests/test_heat_performance_quality.py`、`tests/test_heat_performance_quality_query.py`：前后端契约测试。
