## 四类核心能力

1. **传感器证据落地推断**：14/58 通过。工具多数能返回数据，但最终答案常缺数据来源、时间、
   单位，或没有说明当前证据能否支持趋势/状态判断。
2. **确定性工具增强计算**：2/22 通过。统计工具可用，但答案层经常只保留均值、最大、最小和趋势，
   漏掉标准差、样本数、极差、首末值、斜率、CV和公式。
3. **多工具跨 MCP 编排**：12/15 通过。跨服务并行与多个只读工具组合是当前表现最好的核心能力；
   报告独立记录实际 `server_id/tool/arguments/step_id/elapsed_ms`。
4. **最终答案证据忠实度**：28/123 通过。该项是当前主要发布门禁；工具执行成功不能覆盖答案遗漏
   或“工具有证据、模型却声称没有”的问题。
