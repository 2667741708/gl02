## 3. 通用公式核验

### 3.1 已按原文实现

- `g_H/g_L/g_A`的clip方向正确。
- `z60_X=(60分钟均值-30天中位数)/IQR`。
- `z15std_X=15分钟样本标准差/(IQR/1.35)`。
- `slope30_X=30分钟线性斜率*30/IQR`。
- `TopTempRange=g_H(max(A-D)-min(A-D),10,35)`，并实施四点同分钟完整性门禁。
- `TopPressRange=g_H(max(A-D)-min(A-D),8,25)`，并实施四点同分钟完整性门禁。
- `DPHigh`、`PIBad`、`AirAcceptBad`、`BurdenStall`、`BurdenSlip`、`CoolingRisk`、`HeatProxy`和`DrainProxy`的代数结构与原文一致。
- 单项缺失不补0；评分按可用权重归一，置信度按可用权重/全部权重计算。

### 3.2 尚未完全对应或尚未具备发布条件

1. `StaticPressRange`当前每层只要出现至少2个方向值即可计算，而原文写的是A-F圆周极差；应锁定每层A-F完整同分钟门禁。
2. `BodyHotRisk/BodyColdRisk/BodyTempRange`通过名称前缀动态收集点位，尚未把原文L7-L16、A-H的允许清单和同分钟完整性写死。
3. `BodyColdDuration`当前依赖输入中的`BodyColdDurationMinutes`，没有在通用特征程序中从固定方位历史序列持续计算。
4. `LineLoss`依赖的`normal_level`仍为`null`。
5. `StaticPressRange`和`BodyTempRange`的阶段预警/报警阈值仍为`null`。
6. 冷却系统90天历史同步尚未完成，当前生产端不能据此声称CoolingRisk具备合格30天基线。

## 4. 修复优先级

1. A9已改为一个15权重的`EconomicIntensityEdge`因子；下一步完成30天影子回放与工艺审核。
2. 按原文重新实现C2复合触发，不把未经文档授权的B类70分门槛混入核心公式；若70分作为运营门禁，必须单独配置并明确标注为“发布门禁”而非原文公式。
3. 固定静压力A-F和炉体L7-L16 A-H点位清单、同分钟门禁与缺数原因。
4. 从历史序列计算BodyColdDuration，而不是依赖未说明来源的成品字段。
5. 完成阶段阈值审批、90天历史补数、30天基线重算和至少30天影子回放。
6. 修复后新增文档合同测试，逐条断言33项因子、权重、方向及特殊`max/min/同时成立`语义。
