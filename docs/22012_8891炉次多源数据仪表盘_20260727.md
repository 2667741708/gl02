## 3. 任意时间范围查询

页面支持开始时间、结束时间、炉次号、全文检索、变量列表、分页大小、pSpace 聚合间隔和聚合函数。时间合同统一为左闭右开：

```text
[start, end)
```

常用接口：

```text
GET /api/data-catalog
GET /api/data-source-health?source=vastbase
GET /api/data-source-health?source=postgres_gl02
GET /api/data-source-health?source=pspace
GET /api/data-source-health?source=imes_web
GET /api/data-query?dataset=<白名单ID>&start=<ISO时间>&end=<ISO时间>&page=1&page_size=200
GET /api/data-query?...&format=csv
GET /api/data-query?...&format=xlsx
POST /api/imes-web/login
```

单页最多 5000 行。较长 pSpace 时间窗由服务端按时间跨度选择聚合间隔，避免一次把无限原始点推到浏览器。查询失败、空结果和加载过程分别显示错误、空状态和 loading；导出复用同一个白名单查询合同。

## 4. 正式炉次与铁水化验的精确映射

当前正式链路不再从试样号猜炉次，而是使用两个业务键同时匹配：

```text
t_qpes_inner_batch.heatno  = t_ipes_cond.meltno
t_qpes_inner_batch.batchno = inner_batch_insp_bb.batchno
```

元素编码固定为：

| 编码 | 元素 | 编码 | 元素 |
|---|---|---|---|
| 01 | C | 07 | V |
| 02 | Si | 08 | Cr |
| 03 | Mn | 09 | Ni |
| 04 | P | 10 | Cu |
| 05 | S | 11 | As |
| 06 | Ti |  |  |

每炉铁水仍保留全部样本，并同时提供 Si 的样本数、中位数、最小值、最大值和极差。旧的 `FYYMM-NNN-SSS` 试样号推断只可用于历史审计或缺少正式键的旧数据核查，不能覆盖正式双键关系。

传感器对齐以炉次 `opentime/closetime` 为锚，窗口仍采用 `[start,end)`。烧结矿化验目前只能作为开铁口前 12 小时的上游时间背景；在缺少“料批—入炉—炉次”正式谱系前，不得描述成该炉次的精确入炉批次或因果标签。
