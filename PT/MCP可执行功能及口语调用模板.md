# MCP 可执行功能及口语调用模板

更新时间：2026-07-15

适用范围：8093 智能问答端口中的 GL02 高炉 MCP 数据查询服务。

本文件用于现场测试和后续回归，重点记录：

1. 当前 MCP 可以调用哪些数据点位。
2. MCP 服务可以执行哪些功能。
3. 现场人员可以怎样用口语提问，触发 MCP 查询、统计、画图、报表和历史问答能力。

## 1. 验收口径

判断一次自然语言问题是否成功调用 MCP，不应只看回答文字。

推荐同时查看：

- `mcp_tool_calling=true`：本轮问答进入 MCP 工具调用模式。
- `mcp_prefetch.used=true`：问答代理已提前查库并把结果注入模型上下文。
- `mcp_prefetch.variable`：命中的标准变量，例如 `T_top`、`P_top`。
- `mcp_prefetch.kind`：查询类型，常见为 `latest` 或 `statistics`。
- `mcp_tool_trace`：通用 MCP 工具调用轨迹，画图、报表、快照等更容易出现。
- 回答文本中的数据时间、变量名、趋势图链接或报表路径。

注意：最新值和统计类问题经常由 `qa_mcp_prefetch()` 直接查库并注入上下文，因此 `mcp_tool_trace` 可能为空。不能只因为 `mcp_tool_trace=[]` 就判断“没有查 MCP”。

## 2. 当前 MCP 可执行功能

### 2.1 点位和变量能力

| 功能 | 能解决的问题 | 典型提问 |
| --- | --- | --- |
| 变量检索 | 不知道变量标准名时，按中文口语查候选点位 | “顶压对应哪个点位？” |
| 变量元数据 | 查询变量名、短名、完整点位、说明、用途 | “煤气利用率在系统里叫什么？” |
| 可用变量清单 | 列出当前映射中可查询的变量 | “当前可用的炉顶相关点位有哪些？” |

### 2.2 数据查询能力

| 功能 | 能解决的问题 | 典型提问 |
| --- | --- | --- |
| 最新值查询 | 查询某个点位最新 1 分钟均值 | “现在炉顶压力是多少？” |
| 历史明细 | 查询指定时间段内的时间序列 | “查一下顶压昨晚八点到九点的数据。” |
| 统计查询 | 查询平均、最大、最小、首尾值、趋势、标准差 | “最近半小时顶压稳不稳？” |
| 特征统计 | 结合窗口、波动、趋势和历史基线做特征判断 | “全炉压差最近一小时相对历史基线偏高吗？” |
| 趋势图 | 生成折线、面积、阶梯、散点、双轴或分面 PNG；支持移动平均、极值/最新值标注和参考线 | “画一下顶温和顶压最近一小时双轴走势。” |
| 关系与分布图 | 生成相关散点、相关矩阵、直方分布或箱线图，并返回对齐点数和相关系数等审计指标 | “把顶压、总压差和透气性指数最近两小时相关矩阵画出来。” |

### 2.3 问答辅助能力

| 功能 | 能解决的问题 | 典型提问 |
| --- | --- | --- |
| 最新炉况快照 | 查询当前炉况、诊断、建议、数据质量 | “当前炉况怎么样？” |
| 历史问答检索 | 查询以前是否问过类似问题 | “之前有没有问过顶压波动？” |
| 报表列表 | 列出日报、周报、月报等 Markdown 报表 | “列出最近的日报。” |
| 报表摘要读取 | 读取某个报表片段 | “读一下最近一份日报摘要。” |

### 3.7 炉体温度变量族

炉体温度支持以下模式：

```text
T_body_L{layer}_{sector}
```

其中：

- `layer`：7 到 16 层。
- `sector`：A 到 H 方位。

示例：

```text
T_body_L7_A
T_body_L10_D
T_body_L16_H
```

现场口语示例：

```text
查一下7层A炉体温度现在是多少
10层D炉体温度最近半小时稳不稳
16层H炉体温度最近一小时趋势怎么样
画一下7层A到H炉体温度最近一小时对比
查一下12层各方位炉体温度有没有异常波动
```

### 3.8 静压力 A–F 调用规则

- 已确认并接入 `P_static_upper/middle/lower_A-F` 共18个物理点，不再标记为缺失。
- 只说“20.35米静压力”仍返回 `P_static_lower_mean`；明确说“A到F、六个点、各方位”才展开六个物理点。
- 指定“A、C、F点”只查询三个点。
- 18点已同步进入 PostgreSQL，默认沿用其他传感器的数据库优先策略。

```text
20.35米A到F六个点的静压力现在分别是多少？请带数据时间。
23.49米A、C、F点静压力最近一小时走势画出来。
28.98米B点静压力现在是多少？
把三个高度A到F静压力最近两小时分别画出来。
```

## 7. 2026-07-15 口语回归结果

已使用真实 8093 `/api/qa/chat` 对最新值、统计、多变量比较、趋势图、炉体温度、点位和报表口语做 8 条测试，并与近期炉况、安全边界模板合计完成 23 条审计。

- 8 条请求的 HTTP 均成功返回；按“预取、工具调用轨迹和数据事实”验收时，7 条通过，`帮我找一下最近一份日报` 未调用报表 MCP，不能计为 MCP 成功。
- 初测发现多变量比较只预取一个变量、炉体温度只定位点位两个问题。
- 现已增加同窗 `multi_statistics` 多变量预取，并支持“10层D炉体温度”解析为 `T_body_L10_D` 后直接查询最新值。
- 修复后多变量比较与炉体温度复测均返回完整事实；不需要新增 MCP 服务进程。

完整 Prompt、延迟、安全测试和结果见 [8093 近期炉况口语问答与安全边界 Prompt 模板](8093近期炉况口语问答与安全边界Prompt模板.md)。

## 8. MCP 路由与首 token 边界

- 当前/近期炉况概览若已由每轮实时快照和完整 8 小时统计满足，不进入空的 MCP 工具选择；这类问题的 `mcp_tool_calling=false` 是正常结果，不代表没有读取数据库炉况。
- 具体变量最新值、统计、比较、图表、报表、点位和明确工具请求仍按预取或完整 MCP 工具链执行。
- 规范化后的口语关键词必须非空且长度至少为 2；禁止用“说”等单字触发 MCP，避免普通问句被误路由。
- 是否需要 MCP 由事实来源决定，不能为了显示工具轨迹强制增加一次 27B 工具选择，否则会在没有工具调用时仍阻塞首 token。
