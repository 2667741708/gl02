# GL02 高炉内部仿真与外部细颗粒建模总方案

更新时间：2026-07-18  
设计编号：`REQ-BF3D-INTERNAL-SIM-SURFACE-MODELING-20260718`  
文档状态：设计已固化，尚未执行新的 Blender 资产制作、CFD/DEM 求解、正式 GLB 替换或生产部署。  
适用对象：GL02 高炉 3D 资产、Blender 制作工程、Three.js 实时查看器、炉内数据驱动动画与后续离线物理仿真。

## 1. 文档定位与结论

本方案把后续工作分成两条独立但必须协同的制作线：

1. `BF3D-INT-SIM`：炉内真实结构、工艺对象、数据驱动状态与离线 CFD/DEM 结果的分层建模；
2. `BF3D-SURF-FINE`：炉体外壳从板片、焊缝到氧化、积灰和 3～12mm 微颗粒的多尺度细腻建模。

本方案与现有文档的职责边界如下：

| 文档 | 唯一职责 |
|---|---|
| 本文 | 几何、材质、仿真资产、LOD、浏览器表现和逐阶段制作计划 |
| [高炉内部数据驱动 3D 动画总设计](高炉内部数据驱动3D动画总设计.md) | 数据源、证据等级、统一时钟、事件、C1/C2/C3、回放与动画状态机 |
| [总设计详细规划](总设计详细规划.md) | 全项目资产合同、P00～P70 门禁、Skill/MCP、GLB 与 Three.js 交付 |
| [3D 模型构建显示](../3D模型构建显示.md) | 当前实现、历史制作结果、页面入口和阶段验收记录 |

核心结论：

- 当前固定蓝色线条、参考圆环和固定软熔带只能作为历史教学示意，不能继续承担“真实炉内状态”的角色；
- 炉内应先建立“钢壳—冷却结构—耐火内衬—炉料/气体/液体空间”的真实层级，再叠加实测、插值、估计和仿真对象；
- 外炉壳应保持风化喷涂钢身份，不改成整面砖墙或混凝土；密集微凹凸来自粗糙涂层、积灰、氧化和点蚀的细节法线；
- 砖缝、浇注料孔隙、碳砖和更强砂粒属于剖切后的炉衬；
- 浏览器不直接求解全炉 CFD/DEM。高成本仿真必须离线计算、降采样并生成轻量场景缓存；
- 第一优先级是锁定目前已经有效的 4K PBR 粗糙材质基线，后续炉内制作不得再次覆盖或稀释该表面效果；
- 本文不改变 P50=`not_granted`、P60=`not_granted_preflight_only`、P70 未批准的状态。

## 2. 不可破坏的基线合同

### 2.1 正式资产与坐标

- 正式资产仍是 `高炉前端数据/models/gl02_blast_furnace.glb`；
- 正式合同仍为 190 个节点、29 个网格、23 个材质、115 个现有传感器节点；另行补充 pspace 数据库新增的 18 个静压力点传感器数据，并按其对应位置挂载到 3D 高炉模型中；
- 炉体温度点为 L7～L16 共 10 层、每层 A～H 八点，共 80 点；
- 炉体五段为 `HEARTH/BOSH/BELLY/SHAFT/THROAT`；
- CAD/Blender 源使用 Z-up 和工程尺度；Three.js 使用 Y-up、米制；

## 3. 真实性分层与用户可见说明

每个炉内对象必须携带以下证据等级之一：

| 等级 | 含义 | 允许对象 |
|---|---|---|
| `measured` | 实测值或已核实事件 | 料线、18 个静压力点、80 个炉温点、开/堵铁口 |
| `interpolated` | 实测点之间的有界插值 | 静压力圆周带、炉壳温度连续色场 |
| `estimated` | 经版本化模型估计 | 软熔带、料柱下降、炉缸库存、偏流方向 |
| `simulated` | 经版本化 CFD/DEM 或热化学计算 | 气流场、颗粒轨迹、回旋区和液滴场 |
| `illustrative` | 只用于教学解释 | 没有真实输入的参考过程 |
| `stale` | 数据已过新鲜度 | 冻结的上一帧 |
| `no-data` | 无足够输入 | 隐藏对象或明确空状态 |

界面必须同时显示对象来源、数据时间、模型版本、置信度和“实时/回放/教学”模式。不能用更漂亮的动画掩盖证据不足。

## 5. 炉内真实结构建模

### 5.1 结构建模原则

真实结构与工艺状态分离：

- 钢壳、冷却壁、炉衬和铁口通道属于长期静态资产；
- 料面、矿焦层、软熔带、煤气、液滴和炉缸液位属于时变工艺对象；
- 工程图未确认的厚度、材料牌号、侵蚀轮廓不得写成“真实尺寸”；
- 未确认区域允许先做 `dimension_source=parametric_approximation` 灰模，但界面和文档必须标识；
- 工程图确认后只替换结构参数，不改变数据对象、传感器和前端接口。

### 5.2 外钢壳与剖切厚度

- 保留外轮廓和五段炉型，不为消除视觉折线修改已批准的几何；
- 为剖切建立独立内表面和真实可见厚度，避免单面壳体被裁切后像纸片；
- 剖切边缘使用真实截面材质，不用纯发光线代替所有厚度；
- 钢壳板片、纵横焊缝、加强圈和检修构件优先按实际参考布置；
- 影响轮廓或投影的构件使用几何；不影响轮廓的高频细节进入 Normal；
- 剖切模式至少支持半剖、四分之一剖和局部窗口，生产默认使用最易读且遮挡最少的一种。

### 5.3 冷却结构

- 冷却壁以分段、可实例化的模块建模，不逐个复制高面数网格；
- 水道只在近看或教学模式显示，普通生产模式只显示冷却壁实体；
- 冷却壁与炉衬之间保留清晰的材质和空间边界；
- 冷却结构位置、数量、尺寸在取得图纸前标为 `illustrative_geometry`；
- 后续若接入冷却水温差、流量或热流数据，可按分区着色，但不得把炉壳测温直接等同冷却壁热流。

### 5.4 耐火内衬

炉衬至少拆分为：

1. 炉身耐火层；
2. 炉腰/炉腹过渡耐火层；
3. 炉缸侧壁耐火层；
4. 炉底/炉缸底部耐火层；
5. 铁口及周边强化区；
6. 可选的侵蚀/挂渣覆盖层。

材料名称只有在图纸或检修记录确认后才细化为具体砖种。未确认前使用：

- `refractory_brick_generic`；
- `refractory_castable_generic`；
- `carbon_block_generic`；
- `erosion_layer_estimated`。

炉衬应有独立砖尺度、砖缝、孔隙、烧蚀和挂渣材质；不能复用外钢壳的风化钢贴图。

### 5.5 工艺空间与剖面

- 根据内炉型生成一个闭合的 `PROCESS_VOID`；
- 所有料层、气流、液滴和液位必须被约束在该空间内；
- 剖切面增加截面盖片，避免透明排序暴露背面；
- 结构层可按“钢壳—冷却壁—炉衬—工艺空间”逐层展开；
- L7～L16 选择时只高亮相应高度带和八个点，不把结构层切断或产生缝隙。

## 6. 炉内工艺对象建模

### 6.1 料面与料柱

- 主料线 `L` 通过门禁后驱动料面整体高度；
- `L_south/L_north` 现场对表前不得驱动倾斜；
- 料面使用低阶可变曲面，不使用固定圆柱顶面；
- 料面变化使用有限速率、阻尼和平滑，避免一分钟数据造成跳变；
- 数据过期时冻结并标 `stale`；超过硬阈值后隐藏形变；
- 矿焦层只在上料事件和质量平衡有效时生成；
- 全部颗粒不逐粒建模，采用近表面实例颗粒 + 内部低面数体层的混合方式。

### 6.2 矿焦分层和下降

- 矿批、焦批采用不同 PBR 材质、粒径统计和粗糙度，不用纯色圆环；
- 上料时仅在可见区域生成 GPU 实例颗粒；
- 沉降后将粒子合并为轻量层面，避免对象持续增长；
- 料柱下降由质量平衡、主料线校正和经过标定的下降模型驱动；
- 无布料矩阵时保持中性径向分布并标 `illustrative`；
- 取得溜槽角度、圈次和布料制度后，才允许表现中心/边缘偏布。

### 6.3 软熔带

- 删除固定高度的橙色圆环；
- 软熔带使用闭合体积壳或带厚度的参数化曲面；
- C2 至少输出中心高度、厚度、内外半径、偏心和不确定区间；
- 形状族可包含平坦、倒 V、W 型和偏心候选，但必须由模型选择，不能随机切换；
- 使用 Morph Target 或参数化网格在状态间连续过渡；
- `estimated` 模式显示半透明置信带；`simulated` 模式显示场景版本；
- 无可靠输出时隐藏，不保留固定装饰环。

### 6.4 风口、回旋区、鼓风和喷煤

- 26 个风口保留真实圆周位置；
- 只有总风量、总富氧和总喷煤时，26 个风口统一响应；
- 单风口数据接入后才允许独立强度；
- 回旋区使用受炉内空间约束的低分辨率体积、曲面或预计算网格；
- 喷煤颗粒使用 `Points/InstancedMesh`，不为每个粒子创建独立对象；
- 风口粒子方向、速度、寿命和随机种子由统一控制器管理；
- 总量变化只控制整体密度、尺度或发光，不制造虚假的圆周不均匀。

### 6.5 煤气场和压力

- 18 个静压力点按三高度、A～F 方位直接显示为 `measured`；
- 圆周和纵向色带只做有界插值，标为 `interpolated`；
- 固定蓝色竖线默认移除；
- 真实流线只允许来自 C3 矢量场或经过校准的降阶场；
- C1/C2 可显示压力偏流箭头、等值面或色带，但不得命名为“煤气真实流线”；
- 色标使用固定业务范围或历史基线偏差，不按每帧极值自动拉伸。

### 6.6 滴落带、炉缸、铁水和炉渣

- 滴落区液滴只在估计或仿真输入存在时显示；
- 铁水和炉渣建立独立液面、材质和遮挡顺序；
- 未接入真实液位时，液面高度为 `estimated` 或 `illustrative`；
- `opentime/closetime` 驱动铁口开启、流动和关闭；
- 无瞬时流量时保持统一流束，不用粗细伪装流量；
- 铁量与出铁时长核对单位后，可生成平均流量估计；
- 化验结果只进入炉次结果卡或 C2/C3 模型，不直接把整个液池染成某种成分颜色。

### 6.7 炉体温度和 L7～L16

- 80 个测温点保持原始自发光球或更克制的标记；
- 连续温度场作为独立外壳覆盖层，不改炉壳 BaseColor；
- 选择单层时只显示该层 A～H 八点和对应高亮带；
- 温度覆盖层与细颗粒材质分开计算，不能把 Roughness/Normal 覆盖掉；
- 高亮带应能在外观和剖切模式中正确贴合炉型；
- 历史回放的颜色、数据时间和图例必须同步。

## 7. C1、C2、C3 仿真实施层级

### 7.1 C1：运营孪生

C1 使用已核实数据，不求解内部物理：

- 料线驱动料面；
- 上料事件驱动矿/焦批出现；
- 18 个静压力点及有界插值；
- 80 个炉体温度点和外壳热负荷；
- 开/堵铁口事件；
- 炉次和化验结果卡；
- 实时与历史回放；
- 每个对象显示证据等级和时间。

C1 是第一阶段可交付的真实产品，不应等待 CFD/DEM 才开始。

### 7.2 C2：状态估计孪生

C2 在 C1 上增加：

- 料柱下降速度；
- 批次到达不同炉段的估计时间；
- 压力偏流指数；
- 软熔带高度、厚度、偏心和不确定区间；
- 炉缸铁水/炉渣库存趋势；
- 化验滞后影响和模型置信度。

每个输出必须携带：

```text
source=estimated
model_version
estimated_at
effective_for
input_coverage
confidence
uncertainty
```

### 7.3 C3：离线物理仿真

C3 需要补齐：

- 经核准的内炉型、炉衬侵蚀和冷却边界；
- 单风口/喷煤枪几何与风、氧、煤分配；
- 布料矩阵和溜槽时序；
- 物料粒径、堆密度、孔隙率、软熔和还原特性；
- 炉顶径向煤气数据；
- 冷却水温差、流量和热流；
- 铁水/渣液位、瞬时出铁和铁口状态；
- 可用于标定软熔带、流场和回旋区的现场真值。

正确链路：

```text
工程几何与边界条件
        ↓
离线 CFD / DEM / 热化学计算
        ↓
历史传感器和化验标定
        ↓
误差、适用范围与版本登记
        ↓
降阶场 / 场景库 / 代理模型
        ↓
Three.js 轻量播放
```

浏览器只做显示、插值和场景选择，不承担全炉求解。

## 8. 离线仿真资产到浏览器的轻量交付

### 8.1 标量场

温度、压力、反应度等标量场可选择：

- 低面数等值面；
- 若干二维剖面纹理图集；
- 低分辨率三维纹理；
- 参数化体积壳；
- 按场景离散的 Morph Target。

首期优先低面数等值面和剖面纹理，避免立即依赖复杂体积 Shader。

### 8.2 矢量场

速度或流向场交付为：

- 规则或稀疏采样点；
- 每点位置、方向、强度和可信区间；
- 离线生成的代表性流线；
- 场景切换时的可重复随机种子。

不得把压力标量直接转换成未经校准的“真实流线”。

### 8.3 DEM 和颗粒缓存

- Blender/离线审查可使用 Alembic、点缓存或烘焙粒子；
- Web 交付只保留代表性轨迹、关键时间片和统计密度；
- 同类型颗粒用 `InstancedMesh/Points`；
- 缓存必须支持循环、暂停、seek 和确定性重建；
- 每个场景设置粒子上限和移动端降级。

### 8.4 建议清单

每个仿真场景建议包含：

```text
simulation_id
solver_name
solver_version
geometry_version
boundary_version
input_window
calibration_window
applicable_range
field_units
coordinate_frame
time_step
random_seed
error_metrics
asset_files
sha256
```

候选文件可采用：

- `scene_manifest.json`：语义、版本、坐标和适用范围；
- `scalar_*.bin` 或纹理图集：标量场；
- `vector_*.bin`：矢量场；
- `surface_*.glb`：等值面和 Morph；
- `particles_*.bin`：代表性粒子；
- `preview_*.png`：固定机位验收图。

以上是拟议合同，实施前应先用一个最小场景验证加载、内存和跨浏览器兼容。

## 9. 炉内材质设计

| 对象 | 材质身份 | 主要表现 |
|---|---|---|
| 钢壳截面 | 钢/涂层 | 板厚、切边、克制金属反射 |
| 冷却壁 | 工业金属或确认材质 | 分段、磨损、局部热色 |
| 耐火砖 | 非金属高粗糙 | 砖尺度、砖缝、孔隙、烧蚀 |
| 浇注料 | 非金属高粗糙 | 砂粒、骨料、裂纹与修补 |
| 碳砖/炉缸块体 | 深色非金属 | 层理、磨损、热影响 |
| 矿石/球团 | 非金属颗粒 | 颗粒尺度、灰红褐差异 |
| 焦炭 | 深色多孔 | 孔隙、断面、低饱和高粗糙 |
| 软熔带 | 半透明诊断体 | 温度渐变、置信区间、非实体感 |
| 回旋区/煤气场 | 体积或轻量粒子 | 方向、强度、来源等级 |
| 铁水/炉渣 | 分离液体 | 克制发光、液面与流束层次 |

原则：

- 耐火材料 `metalness=0`；
- 外钢壳金属度由裸钢/涂层/锈/尘遮罩控制，不用固定中间值；
- 热对象发光与数据颜色分离，避免全画面发橙光；
- 内部暖光不能把外壳粗糙度照平；
- 半透明对象限制重叠层数并处理排序；
- 近景砖缝和孔隙可使用低频几何 + 中高频 Normal，远景退化为贴图。

## 10. 外部细颗粒多尺度建模

### 10.1 表面身份

目标不是“把高炉变成水泥柱”，而是形成以下观感：

- 远看仍是连续、厚重、哑光的工业钢壳；
- 中距离可见板片、焊缝、氧化、积灰和涂层老化；
- 近看在斜射光下能看到密集、克制的砂粒/橘皮/点蚀微凹凸；
- 颗粒不应变成白点、亮片、盐粒或规则噪声；
- 剖切内衬才表现砖、水泥/浇注料和更强孔隙。

### 10.2 四级细节

| 级别 | 典型尺度 | 表达方式 | 目的 |
|---|---:|---|---|
| 结构级 | 大于约 50mm | 真实几何 | 轮廓、投影和高光断点 |
| 中尺度 | 20～200mm | 遮罩、BaseColor、Roughness、Normal | 氧化、积灰、剥落、水痕 |
| 微尺度 | 3～12mm | 可平铺 Detail Normal + 微 Roughness | 砂粒、橘皮和点蚀 |
| 亚像素级 | 小于约 3mm | 仅统计性 Roughness，远景关闭 | 避免闪烁与摩尔纹 |

尺度是视觉制作初值，最终应依据现场近景参考和相机像素覆盖校准。

### 10.3 必须进入几何的细节

- 影响轮廓的分段钢板；
- 主纵缝和横向接缝；
- 有可见高度的焊道；
- 加强圈、法兰、螺栓、检修口；
- 局部鼓包、压痕或热变形；
- 风口、铁口和平台连接处的结构转折；
- 剖切可见的钢壳厚度。

使用倒角、加权法线、硬边和正确平滑组塑造高光。不能仅靠一张噪声贴图代替工业结构。

### 10.4 应进入 PBR 贴图的细节

材质使用六层遮罩体系：

1. 深灰绿喷涂/涂层钢；
2. 板边、焊缝、螺栓和积水处的裸钢与氧化；
3. 平台下方、水平凸缘和凹槽的积灰；
4. 接缝、管口和平台边缘向下的水痕；
5. 风口和铁口周边有依据的热影响；
6. 全局低对比微颗粒涂层。

遮罩来源可组合：

- 手工绘制的工程语义遮罩；
- 曲率；
- 局部接触 AO；
- 世界高度与朝向；
- 重力方向水痕；
- 稳定的固定种子噪声；
- 现场照片投影或经过授权的可平铺参考。

程序噪声只提供自然变化，不能决定所有锈蚀位置。

## 11. PBR 通道、UV 与烘焙

### 11.1 通道

| 通道 | 色彩空间 | 要求 |
|---|---|---|
| BaseColor | sRGB | 不烘入灯光、高光或 AO |
| Structural Normal | Non-Color | OpenGL `+Y`，包含板缝、焊缝和较大凹凸 |
| Detail Normal | Non-Color | 可平铺微颗粒，不能替代结构法线 |
| AO | Non-Color | 只表达局部接触，不做全炉脏黑 |
| Roughness | Non-Color | 涂层、锈、尘、裸钢和微颗粒有空间变化 |
| Metallic | Non-Color | 裸钢接近 1，涂层/锈/尘接近 0 |
| ORM | Non-Color | R=AO、G=Roughness、B=Metallic |
| Height 源图 | Non-Color/16bit | 只用于 Blender、烘焙和近景源，不直接承诺 Web 位移 |

### 11.2 纹理规格

建议制作母版：

- 炉壳主图集：4K BaseColor、Structural Normal、ORM；
- 微颗粒平铺图：1K 或 2K Detail Normal + Detail Roughness；
- 炉衬独立图集：2K～4K，不与外壳共用；
- ID/语义遮罩保留源文件，便于重烘焙；
- 浏览器派生 4K/2K/1K 三档；
- KTX2 只有在查看器补齐加载器并通过验证后才启用。

4K 是源母版和高档候选，不代表所有电脑默认加载 4K。

### 11.3 UV

- 锥台炉壳按环向展开；
- 主纵缝放在背侧或真实接缝处；
- 方向性水痕和热影响区域禁止镜像；
- 同级纹素密度目标偏差不超过约 ±15%；
- 4K 图集岛间距初值不少于 16px；
- 管道、平台、法兰和壳体分类型展开；
- AO 使用的 UV 通道必须与 Three.js 实际采样通道一致；
- 烘焙前先做棋盘格、切线方向和背缝检查；
- 一个炉壳段通过后才扩展全炉。

### 11.4 法线合成

Structural Normal 与 Detail Normal 使用 RNM 或等价的正确切线空间合成，不直接 RGB 相加。

浏览器分两条路径：

- 标准路径：预先烘焙或使用第二套重复 UV，把 Detail Normal 合入兼容材质；
- 高档路径：通过受控 Shader/`onBeforeCompile` 做 RNM 和三平面细节采样；
- Shader 失败时自动回退标准 `MeshStandardMaterial`，模型仍可见；
- 法线方向固定为 OpenGL `+Y`，Blender、烘焙器与 Three.js 必须一致。

## 12. 微颗粒 Detail Normal 的距离自适应

### 12.1 屏幕尺度判断

每个材质簇以包围球距离估算颗粒在屏幕上的像素尺寸：

```text
pixelsPerMeter = renderHeight / (2 × distance × tan(fovY / 2))
grainPixels = pixelsPerMeter × medianGrainSize
detailWeight = smoothstep(0.35, 1.25, grainPixels)
```

- 小于约 `0.35px`：关闭 Detail Normal；
- `0.35～1.25px`：平滑增强；
- 大于约 `1.25px`：使用完整强度；
- 计算结果用指数平滑和上下阈值滞回，避免相机轻微移动时闪烁；
- 每秒更新 5～10 次即可，不必每帧重算；
- 不创建临时向量、材质或纹理。

### 12.2 强度建议

初始校准范围：

- 近景：Detail Normal 权重约 `0.35～0.65`；
- 中景：约 `0.15～0.35`；
- 远景：`0`；
- 掠射角可轻微增强，但总增益上限建议不超过 `1.15`；
- 主结构法线始终保留，Detail Normal 只控制微颗粒；
- 强度最终由固定近景相机和旋转检查决定，不能只看一个正面截图。

### 12.3 为什么不能直接增加几何颗粒

在全炉表面真实生成数百万砂粒会造成：

- 面数和 draw call 失控；
- 远景闪烁；
- GLB 体积与显存暴涨；
- 透明/裁剪/LOD 管理复杂；
- 普通电脑无法打开。

因此只有能改变轮廓或明显投影的颗粒/剥落进入几何；密集微颗粒进入 Detail Normal 和 Roughness。

## 13. 粗糙度、环境光与相机

### 13.1 粗糙度设计

- 主体涂层粗糙度可在约 `0.62～0.82` 范围校准；
- 灰尘与锈蚀更粗糙；
- 少量裸钢更低粗糙、更高金属度；
- 不使用全炉统一 `metalness=0.38`；
- 颜色变化保持克制，质感主要来自 Roughness、Normal、结构遮罩和斜射光；
- 微 Roughness 的频率不得与 Detail Normal 完全同相，避免塑料噪声。

### 13.2 环境光

必须保留两套固定环境：

1. `LOOKDEV_NEUTRAL`：中性 PMREM/HDRI 或大面积柔光、无 Bloom，用于判断材质；
2. `PRESENTATION_INDUSTRIAL`：柔和暖主光、冷侧轮廓和克制环境光，用于展示。

Three.js 建议：

- ACES 色调映射；
- 经过固定灰球/金属球校准的曝光；
- PMREM 环境反射；
- 主光以约 25°～45° 斜角扫过炉壳；
- 内切面暖光与外壳冷侧光分离；
- 不依赖高成本实时阴影或全屏 Bloom 来制造“质感”。

### 13.3 近看模式

查看器增加“材质近看”镜头或相机预设：

- 炉壳焊缝/板缝；
- 风口围管和法兰；
- 铁口热影响；
- 炉衬砖/浇注料；
- 外观全炉。

近看模式只改变相机与图例，不切换成另一套未经追踪的材质。

## 14. 质量档位与性能预算

| 档位 | 外壳贴图 | Detail Normal | 环境/采样 | 炉内效果 |
|---|---|---|---|---|
| 高 | 4K 候选或经显存验证的高档资源 | 完整 RNM/三平面、动态距离 | PMREM、8～16 倍各向异性 | 较完整粒子、等值面和低分辨率体积 |
| 中 | 2K 默认 | 保留，降低采样和更新频率 | PMREM、4～8 倍各向异性 | 减少粒子，优先曲面和色带 |
| 低 | 1K | 关闭或预烘焙弱细节 | 基础环境、1～4 倍各向异性 | 关闭体积，保留实测点、料面和关键状态 |

运行目标沿用：

- 高档桌面目标不低于 50FPS；
- 中低档自动降级后不低于 30～35FPS；
- 高/中/低的 draw call 目标分别不高于约 180/120/80；
- 可见粒子初始上限分别约 30,000/12,000/4,000；
- 半透明体积限制屏幕覆盖率；
- 后台标签页停止逐帧动画；
- 自动降级不自动升档，避免画面来回变化；
- 100 次图层/模式切换后对象、纹理、材质和 RAF 数量不持续增长。

贴图档位必须按 GPU 解码后的实际显存评估，不能用 GLB 文件大小代替显存占用。

## 15. Blender 制作工作流

### 15.1 环境和安全

- 从已批准或已锁定的 `.blend` 复制工作副本；
- 不在正式 GLB 上直接编辑；
- Blender、插件、Python、渲染引擎和 GPU 设备写入运行报告；
- RTX/OptiX 必须通过 Blender 设备信息确认，不凭显卡型号推断；
- 未知网页脚本、资产脚本和宏不执行；
- 自动化只写阶段目录，不覆盖上阶段资产。

### 15.2 炉内结构制作

1. 导入炉型折线和当前模型；
2. 建立统一米制、原点和坐标检查；
3. 复制内表面并生成钢壳截面厚度；
4. 建立冷却壁占位模块；
5. 建立炉衬分区和工艺空间；
6. 制作半剖/四分之一剖切灰模；
7. 检查 L7～L16 与 115 点位置；
8. 增加砖缝、孔隙和烧蚀的单区材质小样；
9. 建立料面、软熔带和炉缸的参数化网格/Morph；
10. 只在灰模验收后增加高成本细节。

### 15.3 外壳细颗粒制作

1. 锁定当前 PBR 和固定机位；
2. 选择一个代表性炉壳段做小样；
3. 增加影响轮廓的板片、焊道和接缝；
4. 完成 UV 与棋盘格检查；
5. 制作结构 Normal、BaseColor、Roughness、Metallic、局部 AO；
6. 制作独立 Detail Normal 和 Detail Roughness；
7. 在中性 LookDev 下检查；
8. 以 24 帧整圈旋转检查背缝、闪点和法线方向；
9. 在 Three.js 同机位验证 PMREM、mipmap 和各向异性；
10. 小样通过后扩展到全炉。

### 15.4 烘焙规则

- 使用 cage 或明确射线距离；
- 法线烘焙先做单段；
- AO 仅允许白名单局部接触件参与；
- 平台、塔架、内部结构、传感器和诊断覆盖层不得把炉壳烘黑；
- 所有非颜色通道设置为 Non-Color；
- NormalGL 在 8 位量化后仍须有有效微细节；
- 每次烘焙记录尺寸、边距、采样、种子、文件 SHA 和对象清单；
- 源 Height/Normal 保留高精度母版，浏览器使用派生版本。

## 16. Three.js 实时实现

### 16.1 场景控制

建议扩展稳定接口：

```javascript
window.__BF_CAD_FURNACE_VIEWER = {
  ...existing,
  setCutawayMode(mode),
  setProcessLayer(layerId, visible),
  setEvidenceFilter(levels),
  setSurfaceQuality(level),
  setRenderTime(time),
  loadSimulationScene(simulationId),
  getSimulationState(),
  getSurfaceMaterialState(),
  getAssetAudit()
};
```

### 16.2 材质实现

- 首先保留 GLB 已有 BaseColor/Normal/ORM；
- 高档通过受控材质扩展增加 Detail Normal/RNM；
- 中低档使用标准材质或预合成 Normal；
- 使用 PMREM 和固定曝光；
- 设置经过验证的各向异性；
- UV 或 Detail Shader 创建失败时回退现有 PBR，不阻断模型加载；
- 温度覆盖层、高亮环带和传感器不修改底层炉壳贴图；
- 切换内切面时不能重建或丢弃炉壳材质。

### 16.3 炉内实现

- 静态结构从 GLB 读取；
- 料面、压力覆盖、温度场和标签由 Three.js 运行时生成或更新；
- 粒子优先 `Points/InstancedMesh`；
- 软熔带优先参数网格或 Morph；
- C3 场按 manifest 异步加载；
- 切换场景前预加载最小资源，失败时保留 C1；
- 所有过程对象只读取统一 `render_time`；
- 暂停、seek、隐藏标签页和卸载路由时统一停止；
- `prefers-reduced-motion` 下保留数据状态，取消快速粒子、膨胀和持续漂移。

### 16.4 可观察状态

`.cad-furnace-viewer` 建议增加：

```text
data-sim-mode="c1|c2|c3|teaching"
data-sim-scene="..."
data-sim-evidence="measured|estimated|simulated|mixed"
data-surface-quality="high|medium|low"
data-detail-normal="full|baked|off"
data-cutaway-structure="ready|fallback|error"
data-render-quality="high|medium|low"
```

错误必须显示为明确空状态或降级状态，不能静默回退到固定蓝线和圆环。

## 17. 分阶段实施与批准点

以下 `INT-*`、`SURF-*` 是工作包，不替代 P00～P70 正式批准门禁。

| 阶段 | 工作内容 | 交付 | 通过条件 |
|---|---|---|---|
| `BASE-00` | 锁定 P40/P50/P60 表面和正式模型合同 | SHA、固定相机、对照图 | 115 点、L7～L16、材质源可复现 |
| `INT-10` | 钢壳、冷却壁、炉衬、工艺空间灰模 | `.blend` 候选、四视图、剖面图 | 层次正确、无穿插、无伪尺寸声明 |
| `SURF-10` | 一个炉壳段的多尺度表面小样 | 单段材质球、贴图、近/中/远图 | 近景有颗粒、远景无闪烁 |

## 18. 视觉逐项验收

### 18.1 每次只验证一个变量

固定相机、灯光、曝光和背景，每轮只改变：

- 几何；
- BaseColor；
- Roughness；
- Metallic；
- Structural Normal；
- Detail Normal；
- AO；
- 环境光；
- 炉内状态对象；
- LOD 档位。

禁止同时改灯光、材质、相机和贴图后只凭“更好看”判定。

### 18.2 必须输出的图

外壳：

- 前、后、左、右四个全炉；
- 炉壳焊缝/板缝近景；
- 风口围管近景；
- 铁口近景；
- BaseColor、Roughness、Metallic、Structural Normal、Detail Normal、AO 单通道图；
- 24 帧整圈旋转联系表；
- 近、中、远三距离同材质比较。

炉内：

- 纯灰模剖切；
- 钢壳/冷却壁/炉衬/工艺空间分层；
- C1 料面；
- 18 点静压力；
- L7、L10、L13、L16 单层八点；
- C2 软熔带与置信带；
- C3 一个标量场、一个矢量场和一个粒子场；
- 外观与内切面相同机位对照。

### 18.3 用户视觉验收顺序

1. 先看纯灰模，确认结构层次；
2. 再看无炉内发光的外壳近景，确认粗糙颗粒；
3. 再看全炉远景，确认没有闪烁、盐粒和噪声；
4. 再打开炉衬材质，确认砖/浇注料不污染外壳；
5. 再逐个打开料面、压力、温度、软熔带、风口和炉缸；
6. 每次只开一个数据层，核对图例、时间和证据等级；
7. 最后同时打开综合场景，检查遮挡、配色和性能。

## 19. 自动化与验收合同

### 19.1 模型合同

- 80 个炉体温度点不变；
- L7～L16 每层 A～H 八点；
- 五段炉型根节点不变；
- 传感器 extras 不丢失；
- 新增对象不使用 `SENSOR_` 前缀；

### 19.2 几何

- 无非流形、翻面、零面积和异常缩放；
- 剖切可见真实厚度和截面盖片；
- 冷却壁、炉衬和工艺空间不穿插；
- L7～L16 高亮贴合炉型；
- 近景焊缝有高光断点，远景不形成过密条纹；
- 结构与工艺对象可独立显隐和释放。

### 19.3 材质

- BaseColor 不含照明；
- Normal 为 OpenGL `+Y`；
- AO 仅局部接触；
- Metallic 不出现近二值盐粒；
- Detail Normal 近景可见、远景关闭；
- 无 UV 背缝、方向翻转、静态摩尔纹和旋转闪烁；
- 内切面切换后已有 PBR 通道仍存在；
- 外壳保持钢质身份，炉衬保持非金属粗糙身份。

### 19.4 数据与动画

- 每个对象有 `source/time/confidence`；
- 实测、插值、估计、仿真和示意可自动区分；
- 同一 fixture、随机种子和时间生成相同画面；
- 暂停、seek、恢复和断线重连可重建；
- 化验不会在发布时间之前进入“当时已知”回放；
- 无数据时不回退固定蓝线、固定圆环或虚构软熔带。

### 19.5 浏览器

- Chromium 完成项目规定全部视口；
- Firefox/WebKit 完成四个代表视口；
- 现场 Edge 做冒烟；
- 无横向溢出、关键控件可达、标签不遮挡；
- 页面和控制台意外错误为 0；
- 高/中/低三档各采样至少 10 秒；
- 连续 100 次模式/图层切换无资源增长；
- WebGL/贴图/Shader 失败时保留点位表和明确降级画面。

## 20. 常见失败模式与纠正

| 失败 | 表现 | 优先纠正 |
|---|---|---|
| 外壳水泥化 | 整体发白、无金属身份 | 恢复涂层钢遮罩，砖/浇注料移到炉衬 |
| 颗粒盐点 | 旋转时亮点跳动 | 降低高频对比、远景关闭 Detail Normal、检查 mipmap |
| 摩尔纹 | 远景规则条纹 | 降低频率、增加各向异性、调整 UV 和 LOD |
| 法线方向错 | 一侧凸、一侧凹 | 统一 OpenGL `+Y`，检查切线和镜像 UV |
| 粗糙感消失 | 浏览器比 Blender 平滑 | 检查 PMREM、曝光、法线强度、mipmap、相机距离 |
| 内部发光压平外壳 | 内切面一片橙白 | 分离内外灯光，限制发光和曝光 |
| 半透明排序错 | 软熔带/液体穿插 | 减少透明层、排序、深度预通过或改用不透明等值面 |
| 炉内伪真 | 蓝线/圆环被误当实时 | 默认关闭，强制 evidence 图例和时间 |
| 对象爆炸 | 上料后网格持续增加 | 实例化、合批、对象池和固定粒子上限 |
| UV 背缝 | 转到背面出现断线 | 重排接缝、扩边、旋转审查 |
| 质量档切换跳变 | 画面来回变化 | 只自动降档、不自动升档，使用滞回 |
