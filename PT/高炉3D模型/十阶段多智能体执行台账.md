## 1. 执行原则

1. 十个工作包按门禁推进，不能用并行执行代替阶段批准。
2. 每个 Blender 制作阶段只允许一个主要质量变量，并写入独立 `work/<STAGE>_<DATE>_R*`。
3. 制作智能体不能自批 `approved`；必须依次经过机器检查、只读视觉审查和规范合规审查。
4. 正式 `高炉前端数据/models/gl02_blast_furnace.glb` 在 P50、P60、P70 全部门禁通过前保持只读。
5. 任一阶段不得丢失或移动 115 个 `SENSOR_` 节点、L7～L16 十层、五个 `APPROX_GL02_FURNACE_*` 工艺段。
6. C1、C2、C3 必须分别标识实测、插值、估算和仿真，不能把当前蓝线、圆环或压力插值称为真实 CFD。
7. 剖切后可见的钢壳、冷却壁和耐火层必须使用闭合实体体积，具有独立内外表面与切面封口；禁止零厚度纸片、只靠双面材质或发光线伪装厚度。
8. 未取得 GL02 工程图前，钢壳、冷却壁和炉衬厚度均标为 `E/illustrative`；当前钢壳 45～65 mm 只用于参数化灰模，不得宣传为现场实测尺寸。
9. 每个小阶段必须在其隔离目录或 `stage_summaries/` 中保存《阶段成果总结》，记录输入、命令、产物、断言、视觉/规范结论、保护合同、批准边界、问题和下一停止线。

### 2.1 用户锁定的炉壳表面基准

- 2026-07-18 用户明确选择 R1 的粗糙读感；2026-07-19 在 R1/R2/R3 对比图中再次确认“保留这个 R1，看起来粗糙一点比较有质感”；正式决策号为 `VB-DEC-MAT-001`。
- 后续阶段固定使用 `SURF-20 R5` 作为承载资产：`B=0.16 / D=0.10m / N=0.45 / metallic=0.06 / roughness=0.56–0.82 / shared mapping=0.085`。
- “保留 R1”不等于恢复早期 R1 的 `metallic=0.72`；R5 才是当前已批准的 Blender 材质候选。
- INT-30 及后续阶段只允许在不改变该锁的前提下优化中尺度几何、剖切层、内部对象、灯光和数据覆盖。
- R2E 剖切亮图属于结构辨色证据，不能作为外炉壳最终材质替代方案；最终外观仍以 R1 粗糙微表面为准。
- R2F 的青色测温层只作诊断覆盖；默认全隐、选中层单显，不得以覆盖色替代 R1 材质，也不得把视觉放大解释为炉壳真实机械膨胀。
- R2H 保留 R1 基础 `NormalGL` 与 `normalScale=0.45`，只用 RNM 增加近距离微颗粒；3m 后平滑衰减、20m 关闭，避免中远景噪声。
- R2H 的“炉壳材质检查相机”会临时隐藏内部剖切体、平台和服务塔等遮挡对象，只用于外表面审查，不改变模型资产的默认可见性或生产场景语义。
- R2I 的 55mm 炉腰实体厚度样件只把 R1 用作外表面材质；内表面和切口证据材质不得反向替代外炉壳最终质感。
- R2J 已批准五区实体 Blender 候选：炉缸/炉腹/炉腰/炉身/炉喉为 `65/55/55/45/45mm`，均为 E 级径向示意厚度；`SOURCE_PARITY / ASSEMBLY / SOLO` 必须互斥，不能把测温层放大解释为机械变形。
- 任何更光滑或不同强度的版本必须新开隔离候选，并再次取得用户选择和独立双审。

## 4. 审查智能体调用规则

每个候选完成后按以下顺序调用：

1. `visual_quality_reviewer`：只读查看固定机位和通道图，给出 `approve / iterate / blocked` 建议；
2. `spec_compliance_reviewer`：核对命名、115点、L7～L16、近似标签、阶段报告和停止线；
3. 涉及 GLB/Three.js 时追加 `frontend_asset_reviewer`；
4. 总控 `/root` 汇总机器报告和各审查结论，只有证据一致时更新本台账为 `approved`。

任何审查智能体都不得修改 Blender 或替制作智能体重做资产。
