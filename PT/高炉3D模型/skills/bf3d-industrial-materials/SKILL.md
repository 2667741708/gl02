# 高炉工业 PBR 材质

## 目标外观

将炉体做成深灰绿、哑光、微粗糙的服役钢结构。使用低对比、多尺度、受结构和重力约束的变化，避免均匀噪声、塑料感、全表面橙锈和“熔岩式”发光。

## 五层材质体系

1. **基层钢或涂层**：定义主体色、粗糙度和残余金属裸露区域。
2. **氧化与锈蚀**：集中在焊缝、螺栓、板边、积水点和受损涂层；锈层为非金属。
3. **积灰与烟尘**：集中在平台下方、水平凸缘、凹槽和维护死角；降低金属度并提高粗糙度。
4. **水痕与流挂**：沿重力方向形成低对比纵向变化，从接缝、管口和平台边缘开始。
5. **局部受热变色**：只用于风口、出铁口及有依据的热影响区，范围克制且不使用自发光代替材质。

## 物理规则

- 裸露钢材金属度通常为 0.85～1.0；油漆、氧化、锈和粉尘通常为 0～0.1。
- 主体哑光钢粗糙度以约 0.58～0.82 为起点，再通过遮罩产生变化；不要把一个常数铺满全炉。
- 基础色变化保持低对比；主要质感来自粗糙度、法线和结构遮罩，而不是夸张颜色。
- 微细节法线强度以近景仍可信、远景不闪烁为准；禁止用强 bump 模拟深锈坑。
- 曲率、AO、法线方向和高度只能作为遮罩起点，必须通过手绘或规则修正破除程序化均匀感。
- 风口、平台、管道、支撑、耐火材料和内部物料保留不同材质族，不把整场景统一成一种灰色。

## 节点与 Web 边界

1. 使用 Principled BSDF 建立主材质，明确每个贴图的色彩空间。
2. LookDev 阶段可以使用程序节点，但交付前必须烘焙到标准 PBR 通道。
3. 不依赖 glTF 不支持的 Pointiness、复杂 ColorRamp、对象坐标噪声或自定义着色器作为最终效果。
4. 为 Three.js 保留透明、自发光和传感器材质的独立性；炉壳材质不得遮挡点位。
5. 在中性灯光下校准，不用暖光或 Bloom 掩盖错误材质。

## 门禁

- 材质在灰色中性灯光下仍能区分钢、漆、锈、尘、水痕和热影响区；
- 金属度由像素遮罩决定，没有把锈或粉尘设为金属；
- 近景没有重复噪声、接缝突变、拉伸或法线反转；
- 远景没有摩尔纹、闪烁和过强微法线；
- Blender 烘焙版本和 Three.js GLB 版本外观方向一致；
- 保存 `P30_MATERIAL_APPROVED.blend`、材质球截图、通道图和参数表。
