# 高炉视觉质量验收

## 验收原则

1. 使用固定参考图、固定相机、固定灯光和固定曝光比较版本。
2. 每轮只改变一个维度：几何、UV、材质、灯光、相机、后期或压缩。
3. 先判断轮廓和尺度，再判断材质；几何错误不能靠贴图掩盖。
4. 先验收中性 LookDev，再验收展示灯光，最后验收 Three.js。
5. 所有“通过”都绑定截图、资产 SHA-256、检查表和机器报告。

## 截图矩阵

至少输出：

- 全景：前、后、左、右；
- 细节：炉壳焊缝与板缝、风口围管、出铁口热影响区；
- 材质诊断：BaseColor、Roughness、Metallic、Normal、AO 单通道预览；
- 浏览器：L7、L10、L13 稳态高亮，以及高、中、低质量档；
- 视口：1366×768、1920×1080、768×1024、390×844，并按项目矩阵扩展跨浏览器检查。

## 分项评分

逐项记录 `pass / warn / fail / blocked`：

1. 轮廓与比例；
2. 倒角、法线与硬表面高光；
3. UV 拉伸、接缝、覆盖和纹素密度；
4. 钢、漆、锈、尘、水痕、热变色的物理逻辑；
5. 重复噪声、贴图分辨率和远景闪烁；
6. 灯光层次、曝光、白平衡和裁切；
7. 115 点、L7～L16 与五个工艺段语义完整性；
8. Three.js 色彩、法线、ORM、透明和性能；
9. L7～L13 点位筛选、环带动画和传感器可读性。

## 迭代格式

每轮输出版本与 SHA-256、唯一修改变量、固定机位、观察差异、证据路径、机器检查、继续或回滚结论，以及下一轮唯一变量。

## 交付门禁

- 四全景和三细节无未解释失败；
- 中性灯光和浏览器结果都达到材质目标；
- glTF Validator 错误为 0，结构审计通过；
- 页面错误和控制台错误为 0；
- 传感器未被材质遮挡，L7～L13 高亮不被误认为真实机械膨胀；
- 性能降级后普通设备目标不低于 30 FPS，高档桌面目标不低于 50 FPS；
- 保存 P70 验收报告，不以单张“最好看”的图片替代矩阵证据。
