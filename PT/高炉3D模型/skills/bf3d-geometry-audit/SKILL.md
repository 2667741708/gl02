# 高炉几何审计与硬表面优化

## 输入保护

1. 复制源模型并建立 `P00_SOURCE_LOCKED.blend`；禁止覆盖唯一 GLB、STEP 或 `.blend`。
2. 记录输入 SHA-256、Blender 版本、单位、轴向、原点、包围盒、对象数、网格数和材质数。
3. 导出 115 个 `SENSOR_` 节点的名称、父级、世界矩阵与坐标基线。
4. 导出五个 `APPROX_GL02_FURNACE_*` 和十个 `GL02_SENSOR_LAYER_L*` 分组清单。
5. 用灰模从正、背、左、右和俯视检查轮廓；没有灰模基线不得开始加细节。

## 清理顺序

1. 先处理重复顶点、非流形面、翻转法线、零面积面和异常缩放。
2. 保持对象层级与命名；需要重组时使用新集合包装，不重命名受保护节点。
3. 将炉壳、加强圈、冷却板、平台、管道和支撑分开评估，不对整场景统一应用同一修改器。
4. 使用小尺度倒角捕捉高光，再使用平滑角度或加权法线稳定大面；先做局部样件再扩展。
5. 只在参考照片支持的位置增加板缝、环缝、纵缝、焊缝、法兰、螺栓和检修构件。
6. 将高频细节放入法线贴图；只有影响轮廓、阴影或交互拾取的细节才保留真实几何。

## 高炉专用规则

- 炉壳圆台过渡必须连续，不因按层拆分产生可见裂缝。
- 焊缝与积灰位置服务于材质遮罩，不得做成均匀装饰条纹。
- 风口、围管、出铁口、平台和支撑保留独立材质语义，不合并成单一炉壳网格。
- 内部料柱、软熔带、铁水池和渣层属于解释性可视化，不擅自改写为真实实时物料形态。
- 不移动传感器以“贴合”新炉壳；如发现间隙，记录为模型与点位坐标待核项。

## 门禁

完成 P10 前必须满足：

- 受保护节点计数、名称、父级和世界坐标与 P00 一致；
- 包围盒和原点变化为零，或有经批准的可解释转换；
- 没有新增非流形、翻面或零面积几何；
- 四向轮廓与源模型一致；
- 近景高光连续，倒角宽度没有把结构做成玩具；
- 保存 `P10_GEOMETRY_APPROVED.blend`、审计 JSON 和固定机位灰模图。
