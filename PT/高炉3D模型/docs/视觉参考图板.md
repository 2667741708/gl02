版本：2026-07-18

## 1. 图板规则

本图板把证据分为三类：

| 标识 | 含义 | 能否作为最终外观批准 |
|---|---|---|
| `CURRENT-CANDIDATE` | 项目现有 P30/P40/P50 生成图，用于观察当前实现 | 否 |
| `ISSUE` | 当前图片直接暴露的问题或风险 | 否 |
| `TARGET` | 下一轮应达到的视觉目标和量化检查 | 只有完成固定相机回归并经人工签署后才可以 |
| `REF-PENDING` | 缺少 GL02 现场照片、实物样本、工程图或标定 | 否 |

P30、P40 的阶段记录曾允许流程进入下一阶段，但不等于 P50、GLB、浏览器版本或最终 GL02 资产已经批准。当前 P50 权威状态为：

```text
KEEP_P50_PENDING_NOT_APPROVED
```

## 3. A 板：炉壳材质演进

### A1 — P30 炉壳局部

状态：`CURRENT-CANDIDATE`，仅代表 P30 程序材质方向。

![P30 炉壳局部候选](../work/P30_SHELL_MATERIAL_20260716_223620/renders/neutral_shell/P30_NEUTRAL_SHELL_detail_shell.png)

观察：

- 灰绿色低饱和底色和粉化/氧化斑已经建立；
- 不再是均匀光滑圆柱；
- 大块斑驳仍占主导，微颗粒法线在此图中不够可读；
- 缺少现场板缝、焊缝宽度、维修补漆边界和真实排水路径。

目标检查：

- 1 m 观察距离：出现细砂/喷漆橘皮，但不产生“石膏浮雕”；
- 3–8 m：保留板面粗糙与纵向水痕；
- 20 m 以上：微法线逐渐衰减，只保留宏观板块和轮廓；
- 正面光下不过度显噪，掠射光下有细密高光破碎。

### A2 — P40 固定灯光下的板缝与加强圈

状态：`CURRENT-CANDIDATE`，P40 阶段证据；不是最终 GL02 表面批准。

![P40 Cycles 炉壳细节](../work/P40_FIXED_LOOKDEV_20260717_P36_FINAL/renders/cycles/presentation/P40_CYCLES_PRESENTATION_CAM_DETAIL_SHELL.png)

观察：

- 横向加强圈、纵缝和环向板缝已经可读；
- 暖主光与冷轮廓光能区分曲面方向；
- 斑驳的边界过于连续、平滑，接近程序云纹；
- 焊缝仍缺焊道节奏、局部磨削、热影响和根部接触污渍。

目标检查：

- 板缝不能只有黑线，应具有几何/高度、AO 和粗糙度变化；
- 同一圈焊缝不能使用完全重复的等幅波纹；
- 增加低频钢板热变形，幅值受工程尺度约束；
- 不得用随机噪声平均铺满锈蚀。

### A3 — P50 近景烘焙候选

状态：`CURRENT-CANDIDATE / PENDING`。

![P50 近景 MIP 候选](../work/P50_MASTER_4K_20260717_R1/review/P50_REVIEW_near_mip.png)

观察：

- 4K 烘焙保留了宏观色差和纵向锈水痕；
- 当前报告的有效纹素密度约为 102.32 texel/m，单张唯一图集不足以独立承担 0.2–1 mm 微颗粒；
- NormalGL 的运行时强度为 `0.25`，近景仍显平；
- 目标必须采用“唯一低频图集 + 平铺 Detail Normal/Roughness + 局部 Decal”，不能继续只提高唯一图集分辨率。

目标检查：

```text
Unique atlas：板块、维修、热区、水痕、宏观锈蚀
Tiled detail：0.2–1 mm 橘皮/细砂，物理尺度锁定
Decal：焊缝、点蚀簇、泄水点、检修补漆、局部编号
Runtime：随相机距离衰减，并做法线 MIP/高光抗闪烁
```

### A4 — 用户选择的 R1 粗糙读感锁

状态：`USER-SELECTED / BLENDER-CANDIDATE-APPROVED`；批准边界仅为炉壳 Blender 材质候选。

![R1、R4、R5 掠射对比](../work/SURF_20_20260718_R5/renders/SURF20_R5_10_R1_R4_R5_GRAZING_COMPARISON.png)

受控结论：

- 用户选择左侧 R1 的细密砂粒、橘皮和微凹凸读感；
- 当前主资产不是早期 R1 整套材质，而是 `SURF-20 R5`：恢复 R1 的 `B=0.16 / D=0.10m / N=0.45`，同时保留涂层 `metallic=0.06` 和 `roughness=0.56–0.82`；
- R4 永久保留为更克制的备选，不得覆盖或删除；
- 后续剖切补光、环境光或 Web 色彩管理不能把 R1 微表面“照平”；必须用固定 LookDev 与 R5 做等价对照；
- 未经用户重新选择，不得把 R2/R3/R4 或更光滑版本设为默认炉壳。

## 5. C 板：局部构造

### C1 — 风口

状态：`CURRENT-CANDIDATE`。

![P40 风口细节](../work/P40_FIXED_LOOKDEV_20260717_P36_FINAL/renders/cycles/presentation/P40_CYCLES_PRESENTATION_CAM_DETAIL_TUYERE.png)

当前可取方向：

- 法兰、螺栓、锥形构造和风口区域有独立轮廓；
- 暖/冷光能够读出金属表面方向。

主要问题：

- 缺少 GL02 真实风口/弯头/法兰照片和工程尺寸；
- 管材、保温层、油污、粉尘和热影响尚未形成明确材质族；
- 不得仅凭通用高炉照片确定 GL02 的设备数量和安装角度。

目标：

- 风口本体、法兰、螺栓、保温包覆、积灰和热区分别使用合适材质；
- 接触 AO 只局部作用，不能把法兰整体压黑；
- 热影响有方向和梯度，但不把全部风口涂成高饱和橙色。

### C2 — 出铁口

状态：`CURRENT-CANDIDATE / ISSUE`。

![P40 出铁口细节](../work/P40_FIXED_LOOKDEV_20260717_P36_FINAL/renders/cycles/presentation/P40_CYCLES_PRESENTATION_CAM_DETAIL_TAPHOLE.png)

当前问题：

- 结构仍偏抽象；
- 缺少炮泥、耐材破损、主沟、积渣、焦黑、飞溅和维护痕迹；
- 当前图不支持热态铁水/炉渣的物理批准。

目标：

- 停炉/检修态和出铁热态分成两套场景；
- 热态铁水与炉渣必须保持亮度、黏度、表面壳和流动差异；
- 烟尘、火星和热扰动不得遮挡关键设备或误导温度。
