## 1. 共用约定

### 1.1 来源等级

| 标识 | 含义 |
|---|---|
| M | GL02 实测、扫描、现场标尺照片或直接测量 |
| E | 工程估算、项目当前参数、同类设备经验 |
| S | 仿真或过程模型输出 |
| C | 仅用于解释的概念表现 |
| REF-PENDING | 缺少 GL02 直接证据，不能声称现场还原 |

当前卡册的数值主要是 `E` 级 LookDev 起始值。外部 Commons 图片只能提供形态方向，不能把来源提升为 M。

### 1.2 纹理和距离

- BaseColor、Emissive 使用 sRGB；NormalGL、Roughness、Metalness、AO、Height、Mask 使用 Non-Color。
- 法线约定为 OpenGL `+Y`。
- 标准运行组合：唯一低频 BaseColor/ORM 图集 + 平铺 Detail Normal/Roughness + 局部 Decal/Mask。
- Hero：1024 px/m；Primary：512 px/m；Secondary：256 px/m；Background：64–128 px/m。
- 距离档：近景 `<3 m`；中景 `3–20 m`；远景 `>20 m`。阈值按对象屏幕占比平滑过渡，禁止硬切。
- “Height”只用于离线烘焙、视差或近景受控位移；浏览器不得对整炉做高成本真实位移。
- Metallic 表示材质区域，而不是灰度污渍强度。油漆、灰尘、锈层、水膜和耐材均按绝缘覆盖层处理。

### 1.3 性能档

| 档位 | 材质能力 |
|---|---|
| High | BaseColor + ORM + Macro Normal + Detail Normal + Decal；各向异性按设备需要启用 |
| Medium | BaseColor + ORM + 1 组 Normal；减少 Decal 和 Detail 采样 |
| Low | BaseColor + ORM；细节法线合并或关闭，保留状态色与轮廓 |

所有参数是范围，不允许为了“更明显”把 Normal、Emission、AO 或污渍同时推到上限。

## 2. MAT-STEEL-PAINT-001 老化喷漆钢壳

- **Material ID**：`MAT-STEEL-PAINT-001`
- **材质族 / 对象**：老化涂装碳钢；炉壳、部分主管、检修门外板。
- **来源级别**：当前 P30/P40/P50 项目证据为 E；GL02 现场颜色、漆种和老化分布 `REF-PENDING`。
- **物理尺度**：橘皮/喷砂颗粒 0.2–1.0 mm；粉化斑 5–80 mm；补漆区 0.2–3 m；板面轻微起伏 20–500 mm。
- **BaseColor（sRGB）**：基线 `#48534F`；允许灰绿范围约 `#3F4946–#59635E`，明度变化优先由维护/热区 Mask 驱动。
- **Metalness**：涂层主体 `0.00–0.08`，破漆裸钢区域切换到 `0.85–1.00`；禁止整块涂层使用半金属灰。
- **Roughness**：主体 `0.68–0.84`，粉化 `0.82–0.95`，局部磨损 `0.48–0.68`；P30 起始值 `0.76`。
- **Normal / Height**：Macro Normal 表达板面热变形；Detail Normal 表达橘皮/细砂；近景法线幅度目标 0.05–0.18，按物理平铺尺度锁定；Height 仅用于烘焙和近景焊接影响。
- **GL02 当前实例锁（`VB-DEC-MAT-001`）**：用户选择 R1 的粗糙读感，由 `SURF-20 R5` 承载；固定 `B=0.16 / D=0.10m / N=0.45 / metallic=0.06 / roughness target=0.56–0.82 / shared mapping=0.085`。这是当前实例覆盖值，不反向改写本材质族的通用范围。
- **污渍/覆盖层**：积灰、纵向水痕、维修补漆、涂层粉化、局部破漆；分布必须遵循平台遮挡、重力和热区。
- **纹素密度**：炉壳唯一低频图集 Primary 512 px/m 目标；大面积使用平铺 Detail，不依赖单张 4K 图集承担毫米细节。
- **贴图组合**：`BaseColor_unique + ORM_unique + MacroNormal_unique + DetailNormal_tile + DetailRoughness_tile + Dust/Water/Oxide/Repair masks + Decals`。
- **距离策略**：近景全层；3–20 m 衰减 Detail Normal/点蚀；>20 m 只保留板块、补漆、热区和少量水痕。
- **性能档**：High 7–9 个有效采样；Medium 合并 Detail Normal/Roughness；Low 使用 BaseColor+ORM+单 Normal。
- **禁止事项**：均匀随机锈；大尺度“豹纹/云纹”；BaseColor 烘焙高光；把透明度当成钢壳粗糙感；全炉统一一组污渍。
- **当前资产/状态**：`SURF-20 R5` Blender 炉壳材质候选已按用户选择和视觉/规格双审锁定，候选 SHA-256 为 `4f1dae2804300c2c99462b4a5d7967abd9085a3ffd7170ae26af4e105290471b`；其批准边界不包含正式 GLB、Three.js 或生产替换。P50 4K BaseColor/NormalGL/ORM 仍为 `KEEP_P50_PENDING_NOT_APPROVED`。

## 3. MAT-STEEL-BARE-001 裸碳钢

- **Material ID**：`MAT-STEEL-BARE-001`
- **材质族 / 对象**：裸露碳钢；破漆区、法兰加工面、螺栓、局部检修钢件。
- **来源级别**：E；GL02 裸钢表面处理、氧化状态和维修照片 `REF-PENDING`。
- **物理尺度**：轧制/磨削方向 0.1–3 mm；划痕宽 0.05–1 mm；局部磨亮区 10–200 mm。
- **BaseColor（sRGB）**：P30 基线 `#59615E`；干燥裸钢约 `#4C5251–#68706D`，不可纯黑或银白。
- **Metalness**：`0.85–1.00`；被氧化、积灰、油漆或厚油膜覆盖的像素切换为对应覆盖材质。
- **Roughness**：`0.35–0.75`；P30 起始值 `0.63`；加工面可降至 `0.28–0.45`。
- **Normal / Height**：定向磨削/轧制细纹；点蚀由局部 Mask 控制；划痕用 Normal/Height Decal，不在几何上生成大量细线。
- **污渍/覆盖层**：薄氧化、指向性油膜、边缘积灰、紧固件根部锈。
- **纹素密度**：Hero 1024 px/m 用于风口/出铁口；一般钢件 Secondary 256 px/m + 平铺细纹。
- **贴图组合**：`BaseColor + ORM + directional Normal + oxide/oil/dust masks + scratch decals`。
- **距离策略**：<3 m 显示加工纹和划痕；3–12 m 仅保留粗糙度方向；远景合并为材质实例。
- **性能档**：High 可启用各向异性；Medium 使用定向 Normal；Low 关闭划痕 Decal。
- **禁止事项**：镜面铬感；每个像素随机 Metalness；均匀布满划痕；破漆区边缘无厚度/无过渡。
- **当前资产/状态**：P30 使用 `#59615E / metallic 0.90 / roughness 0.63` 作为候选；尚无独立 GL02 裸钢材质资产，`REF-PENDING`。

## 4. MAT-OXIDE-001 锈层与氧化覆盖

- **Material ID**：`MAT-OXIDE-001`
- **材质族 / 对象**：铁氧化物覆盖；破漆边缘、泄水路径、法兰/螺栓根部、热湿区。
- **来源级别**：E；GL02 锈蚀位置和程度 `REF-PENDING`。
- **物理尺度**：点蚀 0.5–8 mm；锈斑 10–300 mm；流挂宽 2–50 mm、长度 0.1–4 m；层状剥落只用于受证据支持区域。
- **BaseColor（sRGB）**：P30 基线 `#5B4032`；干锈 `#4A332B–#7B4B2E`，湿锈更暗但不靠纯黑。
- **Metalness**：`0.00–0.08`；锈是绝缘覆盖层，不能沿用下方钢材的 1.0。
- **Roughness**：`0.72–0.98`；湿润边缘可局部降至 `0.45–0.72`。
- **Normal / Height**：点蚀向内、厚锈向外；Height 0.2–3 mm 仅近景/烘焙；远景只保留色和粗糙度。
- **污渍/覆盖层**：与水痕、积灰、破漆和热影响组合，但必须有源点和重力方向。
- **纹素密度**：平铺微锈 512–1024 px/m；大流挂使用唯一 Mask/Decal。
- **贴图组合**：`oxide BaseColor + ORM + pitting Normal/Height + source/runoff mask + edge breakup`。
- **距离策略**：近景显示点蚀/剥落；中景显示斑块和流挂；远景只保留少量纵向色差。
- **性能档**：High 叠加点蚀和湿边；Medium 合并为一张 Decal；Low 仅颜色/粗糙度 Mask。
- **禁止事项**：全炉随机橙锈；锈从无构造关系的位置开始；把热变色当锈；使用均匀分形噪声代替流挂。
- **当前资产/状态**：P30/P50 已有氧化和纵向流痕候选；真实位置和尺度未批准，`REF-PENDING`。

## 5. MAT-WELD-001 焊缝与热影响区

- **Material ID**：`MAT-WELD-001`
- **材质族 / 对象**：焊缝；炉壳环缝/纵缝、管道焊口、加强件根部。
- **来源级别**：现有几何 E；焊缝形式、宽度和位置需工程图/M 证据，当前 `REF-PENDING`。
- **物理尺度**：焊道宽 6–30 mm、余高 1–5 mm 为起始估算；具体值必须按接头形式和图纸修订。
- **BaseColor（sRGB）**：焊缝金属 `#4A4F4E–#626866`；周围热影响区低饱和褐/蓝灰，仅在裸钢或破漆条件下出现。
- **Metalness**：裸焊缝 `0.85–1.00`；涂装覆盖后的焊缝 `0.00–0.08`。
- **Roughness**：焊道 `0.38–0.72`；磨削面 `0.28–0.50`；积灰根部 `0.75–0.95`。
- **Normal / Height**：Hero 焊缝使用低段几何或 Curve；一般焊缝用 Height+Normal；道间节奏需要变化；根部局部 AO。
- **污渍/覆盖层**：磨削、烟尘、热影响、局部补漆、沿根部积灰/锈。
- **纹素密度**：Hero 1024 px/m；炉壳 Primary 512 px/m；长焊缝使用平铺焊道 + 路径 Mask。
- **贴图组合**：`weld strip BaseColor/ORM/Normal/Height + HAZ mask + grind/dust decals`。
- **距离策略**：<5 m 保留焊道节奏；5–20 m 简化为高度/阴影线；远景合入板缝。
- **性能档**：High Hero 几何+材质；Medium Normal/Height Decal；Low 单条板缝线与局部 AO。
- **禁止事项**：所有焊缝同样波纹；把焊缝画成纯黑线；无图纸却宣称真实宽度；AO 形成大范围黑边。
- **当前资产/状态**：P40 炉壳细节能看到板缝/加强圈，P50 AO 白名单包含焊缝；几何仍为近似，最终未批准。

## 6. MAT-DUST-001 干燥积灰覆盖

- **Material ID**：`MAT-DUST-001`
- **材质族 / 对象**：覆盖层；平台、加强圈上表面、法兰凹处、设备背风面、混凝土角部。
- **来源级别**：E；GL02 粉尘颜色、来源和清扫周期 `REF-PENDING`。
- **物理尺度**：颗粒 10–500 μm（不逐粒建模）；沉积斑 20–500 mm；厚积灰边界 1–20 mm 仅近景。
- **BaseColor（sRGB）**：P30 基线 `#625F56`；允许 `#56544E–#777267`，根据焦粉/矿尘来源校准。
- **Metalness**：`0.00`。
- **Roughness**：`0.86–0.98`；P30 起始值 `0.92`。
- **Normal / Height**：微粒使用高频 Detail Normal；厚积灰只在水平 Hero 面用受控 Height/几何。
- **污渍/覆盖层**：可吸附水形成暗边；与油污接触时产生黏附聚集；不平均覆盖垂直迎风面。
- **纹素密度**：平铺 512 px/m；边界/清扫痕 Decal 1024 px/m。
- **贴图组合**：`dust color/roughness + world-up mask + cavity/AO mask + airflow/exclusion mask + sweep decals`。
- **距离策略**：微颗粒 <5 m；中景只保留沉积分布；远景仅影响大色块和轮廓明度。
- **性能档**：High world-up/cavity 组合；Medium 使用烘焙 Mask；Low 合并进 BaseColor/ORM。
- **禁止事项**：全表面同强度；垂直面出现水平积层；以 AO 代替积灰；灰尘产生金属高光。
- **当前资产/状态**：P30 有软积灰候选，评审要求在全炉烘焙后复核；无现场颜色/分布批准，`REF-PENDING`。

## 7. MAT-WATER-001 水痕、潮湿与薄水膜

- **Material ID**：`MAT-WATER-001`
- **材质族 / 对象**：覆盖层；冷却/排水附近、平台边缘、法兰下方、混凝土潮湿区。
- **来源级别**：E；真实泄水点与检修状态 `REF-PENDING`。
- **物理尺度**：细流痕 2–20 mm；汇流 20–100 mm；长度 0.1–5 m；薄膜厚度不显式建模。
- **BaseColor（sRGB）**：P30 候选 `#37423E`；以底材变暗 5%–25% 为主，不涂成蓝色。
- **Metalness**：水膜本身 `0.00`；不改变下方材质区域身份。
- **Roughness**：湿膜 `0.08–0.35`，干涸水垢 `0.62–0.92`；P30 的 `0.80` 更接近干痕而非鲜明湿膜。
- **Normal / Height**：薄膜不做凸起；干涸沉积边缘用极弱 Normal/Height；水滴仅 Hero 近景、数量受限。
- **污渍/覆盖层**：与锈、粉尘和水垢联动；源点、分叉、汇流和末端必须符合重力。
- **纹素密度**：流痕 Decal 512–1024 px/m；长距离路径使用唯一 Mask。
- **贴图组合**：`runoff mask + roughness darkening + oxide/limescale secondary mask + optional normal edge`。
- **距离策略**：<5 m 可读湿/干边；中景保留纵向暗带；远景只保留主路径。
- **性能档**：High 独立覆盖层；Medium 烘焙进 ORM/Color；Low 仅一张 Mask。
- **禁止事项**：把水痕画成蓝线；无源点的随机竖线；所有平台下等距复制；透明排序依赖大面积水面。
- **当前资产/状态**：P30/P50 有纵向流痕候选；未验证 GL02 排水路径，`REF-PENDING`。

## 9. MAT-HEAT-001 热影响、氧化色与涂层粉化

- **Material ID**：`MAT-HEAT-001`
- **材质族 / 对象**：状态覆盖层；风口、出铁口、热风管、炉缸附近的金属/涂层。
- **来源级别**：视觉起始值 E；运行温度驱动可为 M/S；GL02 热像/温度点到表面映射仍需验证。
- **物理尺度**：热影响带 20 mm–2 m，取决于设备结构；边界应渐变。
- **BaseColor（sRGB）**：涂层以粉化/褪色为主；裸钢可出现低饱和灰→黄褐→蓝紫氧化色，但不按彩虹均匀铺设。
- **Metalness**：裸金属仍 `0.85–1.00`；厚氧化/粉化层 `0.00–0.10`。
- **Roughness**：粉化涂层 `0.82–0.96`；裸钢热色 `0.35–0.70`。
- **Normal / Height**：热色本身无高度；涂层失效和氧化皮可有微弱裂纹/剥落法线。
- **污渍/覆盖层**：与烟尘、积灰、冷却水和维修补漆区联动；不能简单等同锈。
- **纹素密度**：热区唯一 Mask 512 px/m；裂纹 Detail 1024 px/m 平铺。
- **贴图组合**：`temperature/zone mask + coating fade + heat tint + roughness shift + scale/crack detail`。
- **距离策略**：所有距离保留大热区；近景才显示裂纹/氧化皮。
- **性能档**：High 数据驱动混合；Medium 预烘焙区段；Low 使用状态色覆盖，不增加额外法线。
- **禁止事项**：把温度点线性映射成彩虹金属；热变色=锈；以 Emissive 表示普通温升；无数据时保留上一时刻热区而不标 stale。
- **当前资产/状态**：现有炉壳有少量暖色方向，但尚未形成受控热影响 Mask；数据驱动与现场标定均待完成。

## 21. 批准规则

单张材质卡只能在以下条件全部满足后从 `REF-PENDING` 或候选转为批准：

1. 对应 GL02 现场/工程参考已登记且权限明确；
2. 真实尺度、色彩参考和材质区域身份已确认；
3. Blender 中完成中性光与展示光材质球、对象近景和四向图；
4. Three.js 同相机、同环境对照通过；
5. 近/中/远距离无重复纹理、摩尔纹、法线闪烁和接缝；
6. High/Medium/Low 三档降级行为符合卡片；
7. 贴图尺寸、采样数、显存和帧时间通过预算；
8. 审核记录写入资产 SHA256、参数版本、截图和批准人。

在此之前，卡册中的参数是可执行起始规范，不是 GL02 实物测量结论。
