# 想法 001：用有工艺意义的神经元预测铁水 Si

记录日期：2026-07-26  
状态：待历史数据验证

## 原始思想

现有炉况规则引擎的每个规则项都可以理解为一个具有明确工艺含义的“神经元”：

1. 输入不是未经选择的全量原始数据，而是提炼好的时间序列统计、趋势和波动；
2. 阈值决定神经元何时开始响应；
3. 权重决定该神经元对最终炉况判断的贡献；
4. 调整权重、阈值和时间窗，本质上就是受专家知识约束的模型调参；
5. 每个中间响应都能解释，不需要依赖不可审计的黑箱结论。

同一思想可延伸到铁水 Si：

```text
传感器时间序列 + 炉料化学背景 + 前序炉次Si
                     ↓
有意义的语义神经元
                     ↓
Si中心值 + 分布区间 + 越界概率 + 神经元贡献
```

## 第一版语义神经元候选

| 神经元 | 主要信息 | 需要验证的假设 |
|---|---|---|
| 热输入 | 风温、富氧、喷煤、理论燃烧温度的水平与趋势 | 热储备增强通常推动 Si 上行，但存在时滞和耦合 |
| 透气性 | 总/上下部压差、透气性指数、风量受限情况 | 透气性变化会改变还原、传热和热状态稳定性 |
| 煤气流分布 | A-D顶温、顶压、炉身温度周向偏差 | 偏流和分布不均会增加 Si 波动而非简单改变均值 |
| 炉体热状态 | 7-16层炉温水平、斜率、周向极差 | 炉体热状态对后续出铁 Si 有滞后关联 |
| 炉料化学负荷 | 入炉 TFe、SiO2、Al2O3、CaO、MgO、S 等干基加权值 | 必须取得精确炉次谱系后才能作为高置信度输入 |
| 渣系背景 | 炉渣 R2、FeO、MgO/Al2O3 及前序炉变化 | 可用于解释脱硫、还原和渣铁质量联动 |
| 前序炉惯性 | 前1-6炉 Si 中位数、范围和趋势 | Si具有自相关，前序炉是强基线但不能掩盖过程变化 |
| 出铁与排放 | 开堵口节奏、铁量、渣量、双铁口温度 | 影响观测对齐和同炉试样离散程度 |
| 数据可信度门 | 覆盖率、缺点、时间滞后、谱系置信度 | 数据不足时降低置信度或拒绝预测 |

## 为什么不能只复制现有规则引擎

炉况规则输出主要是类别和分数，Si预测需要连续数值及概率分布。因此需要增加：

- 炉次级时间锚点；
- 连续目标回归；
- 多试样中位数、最小值、最大值和极差；
- 残差或分位数校准；
- 按时间滚动的回测；
- 对原料谱系和取样时间不确定性的显式处理。

## 可拓展方向

1. **神经元内部从固定阈值升级为单调分段函数**：保留意义，同时允许数据学习
   拐点和斜率。
2. **神经元之间增加少量受控交互**：例如“热输入×透气性”“炉料SiO2×渣系”
   等，禁止无限制全连接。
3. **多任务输出**：共享过程神经元，同时预测铁水 C/Si/Mn/P/S、炉渣 FeO/R2
   和渣铁量。
4. **工况分型模型**：正常顺行、热制度上行、热制度下行、气流异常可分别校准
   输出层，但必须避免样本过少。
5. **相似炉次检索**：每个预测同时返回历史上神经元激活模式最相似的炉次。
6. **建议闭环**：预测模型只提供风险和贡献；现有规则引擎负责安全过滤；最终由
   高炉长确认并记录结果。

## 关键反例

- 单个 Si 试样异常不等于整炉热状态异常。
- 热输入提高不保证 Si 必然升高，气流、炉料和排放会改变结果。
- 高相关传感器不等于可调控制变量。
- 训练集拟合好不等于跨月、跨工况稳定。
- 用化验发布时间之后的传感器预测该化验属于标签泄漏。
