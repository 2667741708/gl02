# EXP-SI-V1-SEMANTIC-001 实验方法

状态：固定方法，允许执行探索性训练  
数据等级：V1代理时间对齐，不是生产金标准

## 1. 实验问题

验证“现有炉况规则特征可以视为有意义神经元输入，并用于预测一炉铁水Si分布”
是否优于简单历史基线，同时比较提炼后的规则特征与全量传感器快照。

## 2. 样本单位

训练单位固定为“一炉一行”，不是“一份试样一行”：

- 临时炉次组由 `si_sample_no` 去掉最后的试样序号得到；
- 同组全部试样用于计算Si中位数、最小值、最大值、极差和样本数；
- 特征行选择该炉次组最早的 `feature_end_ts`，避免使用同炉较晚试样对应的
  过程快照；
- 正式V2必须用IMES `meltno` 代替临时炉次组。

## 3. 时间边界

- 当前特征截止时刻仍为 `si_result_ts - 120分钟`；
- 前序炉Si只有在其 `si_result_max_ts <= 当前feature_end_ts` 时才允许使用；
- 同炉当前目标绝不进入输入；
- 化验发布时间不是确认取样时间，因此本实验只用于探索和基线。

## 4. 公共处理层

公共层可以被所有实验复用：

1. 试样号清洗和炉次组生成；
2. 一炉多试样标签聚合；
3. 最早安全特征行选择；
4. 前1/3/6个已发布炉次Si特征；
5. 按时间顺序固定训练、验证、测试炉次；
6. 数据字典、来源哈希和切分清单。

公共层禁止做：

- 全量均值/方差标准化；
- 全量中位数填补；
- 用验证集或测试集选择特征；
- 用测试集选择模型或残差区间。

## 5. 固定切分

按 `feature_end_ts` 递增：

- 前70%炉次：训练集；
- 中间15%炉次：验证集；
- 最后15%炉次：测试集。

同一炉次只出现一行，所以不可能跨集合。验证集用于模型选择和残差分布标定，
测试集只做一次最终评价。

## 6. 模型

| 模型 | 输入 | 作用 |
|---|---|---|
| `previous_heat` | 最近一炉已发布Si | 最简单自回归基线 |
| `recent3_median` | 最近3炉已发布Si中位数 | 稳健历史基线 |
| `rule_ridge` | 规则特征、诊断分数、前序炉Si | 线性可解释基线 |
| `rule_hist_gradient` | 同上 | 非线性规则特征基线 |
| `full_extra_trees` | 规则特征、传感器快照、前序炉Si | 检查原始点是否增加信息 |
| `semantic_neurons` | 按工艺分组的规则特征 | 有意义神经元主实验 |

语义神经元分组：

- 热输入；
- 透气性与压差；
- 煤气流和炉体分布；
- 料线与装料状态；
- 现有炉况诊断；
- 前序炉Si惯性。

第一轮允许数据无约束学习正负贡献，用于发现与专家先验冲突的神经元；第二轮
经专家评审后再加入方向约束，不能先把预期结果硬编码成结论。

## 7. 语义神经元训练

每个神经元先用所属特征训练一个岭回归子模型。为避免输出层看到同一训练样本的
过拟合预测，神经元激活使用时间序列交叉拟合：

```text
训练段过去数据
→ 神经元子模型
→ 预测下一折
→ 汇总折外响应
→ 学习阈值、尺度和输出权重
```

最终神经元：

```text
z_j = sigmoid((group_prediction_j - threshold_j) / scale_j)
Si = intercept + Σ(weight_j × z_j)
```

保存神经元内层特征系数、填补中位数、标准化统计、阈值、尺度和输出贡献。

## 8. 指标

- MAE、RMSE、R²；
- 绝对误差不超过0.05%和0.10%的命中率；
- `<0.20% / 0.20%～0.40% / >0.40%` 三区间分类准确率；
- 低Si召回率和高Si召回率；
- 验证集残差标定的P10～P90区间在测试集的覆盖率；
- 拒绝预测率和输入缺失率。

模型按验证集MAE选择，测试集不得参与选择。

为保证产物逐字节复现，随机种子固定为 `20260726`，首轮ExtraTrees固定单线程；
依赖版本、平台和所有产物SHA-256写入运行清单。

## 9. 固定产物

- 公共炉次级数据；
- 固定切分清单；
- 数据和切分清单SHA-256；
- 实验配置；
- 各模型验证/测试指标；
- 测试集逐炉预测；
- 语义神经元配置和特征合同；
- 模型文件；
- 报告和运行环境版本。

## 10. 实验结论边界

即使测试集表现良好，也只能说明V1代理数据上的探索结果。进入影子运行前必须：

1. 用正式 `meltno` 重建；
2. 使用真实开堵口/取样时间；
3. 生成30/60/120/240分钟完整窗口统计；
4. 增加原料谱系及炉渣背景；
5. 做跨月滚动回测和概率校准；
6. 经高炉专家评审神经元方向。
