# V10～V12 时延场、标签可靠性与专家集成方法

日期：2026-07-27

## 1. 目的

V6～V9已经覆盖累计窗口统计，但“60分钟均值”包含最近30分钟，无法直接区分
过程响应发生在30～60分钟还是0～30分钟。V10首先从嵌套累计统计恢复非重叠
时延带，再用圆周谐波表达静压力场和炉体热场的方位偏流。

后续两项实验分别检验：

- V11：同炉多试样离散能否作为训练标签可靠性；
- V12：原热状态专家与新时延/空间场专家能否提供稳定互补。

所有选择只使用2026-04、2026-05扩展折和固定2026-06验证段。2026-07已经被
多个版本读取，只能作为历史对照。

## 2. V10非重叠时延带

由累计窗口的`mean × count`恢复：

```text
0–30 / 30–60 / 60–120 / 120–240 / 240–480分钟
```

例如：

```text
mean(30–60)
= [mean(0–60)×count(0–60) - mean(0–30)×count(0–30)]
  / [count(0–60)-count(0–30)]
```

若区间有效点数不大于0，结果保持缺失，禁止补0。每个物理点再生成：

- 各时延带均值与覆盖率；
- 最近时延带相对远端各带的差；
- 相邻时延带曲率；
- 向预测截止时刻的带均值斜率；
- 时延带波动和极差。

共新增2,660个时延带特征。

## 3. V10空间场模态

对有固定圆周顺序的点位计算离散傅里叶一阶和二阶模态：

- 炉顶温度、炉顶压力：A～D；
- 下/中/上三高度静压力：A～F；
- 炉身7～16层温度：A～H。

每个场保留圆周均值、标准差、极差、谐波余弦分量、正弦分量和幅值；炉身进一步
计算一阶方位偏流在7～16层的纵向相干性和幅值斜率。少于75%方位有效时保持
缺失，不把缺点当作零值。

共新增1,390个空间场模态。

## 4. V11标签可靠性

发布与评价目标始终为正式整炉Si中位数。仅在训练时比较：

- 中位数；
- 75%中位数+25%均值；
- 50%中位数+50%均值；
- 均值；
- 按试样数和炉内标准差构造的可靠性权重；
- 可靠性权重与90天时间衰减组合。

这些标签统计不进入推理特征。结果若选择回中位数+均匀权重，应解释为同炉离散
包含真实过程变化，不能简单当作测量噪声删除。

## 5. V12专家集成

四个分量为：

1. 直接ExtraTrees；
2. 热状态XGBoost残差；
3. 原热状态LightGBM残差；
4. V10时延/空间场LightGBM残差。

使用0.05步长的非负单纯形权重，权重和严格为1。权重仍只由4/5/6月选择。

## 6. 评价

- MAE、RMSE、Bias；
- `±0.02/0.03/0.04/0.05/0.10`命中率；
- 跨月稳健分数：`mean(MAE)+0.5×std(MAE)`；
- 与V9历史预测做10,000次配对bootstrap，仅用于判断差异不确定性；
- 任何7月改善均不得重新用于选择下一模型。

全部产物保持`experimental_offline`。真实铁水温度标签仍为0，温度和热状态概率
联合头继续被数据合同阻止。
