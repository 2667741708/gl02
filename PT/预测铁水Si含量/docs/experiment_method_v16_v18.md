# V16～V18 残差选择与CatBoost实验方法

需求：

- `REQ-SI-RESIDUAL-ALIGNED-SELECTION-V16-20260727`
- `REQ-SI-CATBOOST-ORDERED-V17-20260727`
- `REQ-SI-CATBOOST-PLAIN-V18-20260727`

## 1. V16：残差对齐特征选择

V13最终模型学习的是相对已发布历史Si基线的残差，但V13的新时延/空间场重要性
仍按完整Si排序。V16在每个训练折内改用：

```text
selection_target = target__Si_representative - published_history_baseline
```

对8,173个时延带、空间场和时延矩候选重新做ExtraTrees重要性排序，并比较
200/350/500/800项配方。最佳V16专属候选为800项，稳健分数`0.058597`，仍
弱于V13的`0.057979`；最终选择退回V13。

完整运行约850.7秒。继续用高维森林反复排序的计算收益不足。

## 2. V17：Ordered CatBoost

V17不重新训练V13选择器，而是从V13不可变`selection_audit.json`重建逐折配方。
复用前必须通过：

- 数据集、炉次目标、试样、点位目录和时序清单SHA-256；
- 训练行数；
- 配方特征数量；
- 当前输入字段存在性。

验证/测试标签不进入缓存。CatBoost版本为`1.2.10`。

V17两次运行均在1,004秒外层时限终止：

- 001：V9/V13两配方×5配置×3折；
- 002：V13单配方×3配置×3折。

第二次残留进程最高约3.31 GB，按精确PID清理。两次失败目录均保留
`.failed_timeout_1004s`后缀，不得作为完成实验引用。

## 3. V18：Plain CatBoost

V18复用同一缓存合同，仅比较：

- Plain MAE、深度6、残差目标、200轮；
- Plain RMSE、深度6、残差目标、200轮。

最终选择RMSE候选：

- 预测试稳健分数：`0.060185`；
- 历史MAE：`0.049539`；
- `±0.02=23.26%`；
- P10～P90覆盖率：`70.64%`。

均弱于V13，不进入前瞻协议。CatBoost只保留为离线实验环境依赖，不加入生产
运行依赖。

## 4. 结论

当前推荐主方法仍为V13。下一轮不再扩展CatBoost参数网格，应基于未来盲测炉次
进行误差分段、月份漂移和热状态区间诊断。真实铁水温度标签仍缺失，温度联合头
保持阻止。
