# 铁水 Si 实验总结与“语义神经元 + 深度时序网络”路线

问题编号：`Q-SI-HYBRID-SEMANTIC-DEEP-20260726`

## 1. 总判断

“有意义神经元”方向值得继续，但需要严格区分四个层次：

1. **微特征**：单点的末值、均值、斜率、波动、覆盖率；
2. **物理概念**：压差分配、喷煤设定—实际偏差、圆周不均、纵向传播；
3. **语义神经元**：热输入、透气性稳定、煤气流分布、炉料负荷等专家可理解状态；
4. **深度表征**：ResTCN、1D ResNet 或 Transformer 从原始序列学习的不可完全
   命名残差信息。

项目的创新点不应是把几百个字段都叫作神经元，而应是建立一个可干预的语义
概念层，再让深度网络只补充概念层解释不了的残差。

这与 Concept Bottleneck Model 的思想一致：模型先预测人能理解的概念，再由
概念预测目标。神经加性模型则适合学习每个概念的非线性响应曲线，并保持贡献
可见。相关原始研究见 [Concept Bottleneck Models](https://proceedings.mlr.press/v119/koh20a.html)
和 [Neural Additive Models](https://arxiv.org/abs/2004.13912)。

## 2. 三轮实验到底证明了什么

| 阶段 | 标签和输入 | 主要结果 | 科学结论 |
|---|---|---|---|
| V1 | 试样号临时炉次；260个代理快照/规则特征 | ExtraTrees MAE 0.0498；6神经元 MAE 0.0551 | 语义神经元优于历史惯性基线，但不及全量树；异常召回为0 |
| V2 | 同一代理数据；6组拆成21组 | 21神经元 MAE 0.0500；全量树0.0498；±0.05命中均约60%～62% | 拆细语义组有效，但尚未超过强基线 |
| V3 | MES正式meltno；开铁前133点60/120分钟特征 | ExtraTrees MAE 0.048851；±0.05命中64.53%；分布P50 MAE 0.048312 | 正式标签与真实时序基线建立，但分布校准、月份稳定性仍不足 |

V1最重要的反结果是：总体MAE尚可，但低Si和高Si召回为0，预测被压缩在正常
区间。V2说明“有意义神经元”不是无效想法，但只拆分概念数量不会自动提高
`±0.05`命中。V3解决了正式炉次和预测截止问题，却仍有以下限制：

- 验证MAE `0.062120`，测试MAE `0.048851`，两个连续时间段难度明显不同；
- 80%代表值区间平均宽度 `0.210311% Si`；
- 预测分布带完整包住实际P10-P90仅 `23.55%`；
- 真实取样时间、铁口和出铁阶段仍缺源；
- 未加入精确炉次谱系的炉料化学成分。

## 3. 不要混淆“±0.05准确度”和“0.05分布宽度”

至少2个试样的2,026炉中，同炉Si极差：

- 中位数：`0.10% Si`；
- P75：`0.17% Si`；
- P90：`0.24% Si`。

因此：

- “代表值误差不超过±0.05”是可以继续追求的点预测指标；
- “整炉P10-P90总宽度压到0.05”与当前同炉真实离散程度冲突，不能靠强行缩窄
  区间实现；
- 分布模型应优化校准覆盖和条件宽度，而不是只追求窄。

## 4. 推荐的混合架构

```text
133点原始分钟序列 ──> ResTCN/1D-ResNet ───────────────┐
                                                       │
规则特征与物理派生 ──> 20～40个语义概念 ──> NAM/HONAM ├─> 门控融合
                                                       │       │
炉料/炉渣/炉次静态量 ──> 小型表格编码器 ──────────────┘       │
                                                               ↓
                                     代表Si + P10/P50/P90 + 越界概率
```

建议输出写成：

```text
y = y_semantic + gate(data_quality, regime) × clip(y_residual, -r, +r)
```

- `y_semantic`：由可解释语义神经元产生；
- `y_residual`：深度时序分支学习语义层遗漏的信息；
- `gate`：数据质量差或工况超分布时自动减小黑箱分支权重；
- `r`：初始限制黑箱残差幅度，避免深度分支完全吞掉语义解释。

这不是把 Transformer 和规则简单拼接，而是“可解释主干 + 有界残差”。深度
网络只有在时间外消融证明有稳定增益时才保留。

### 为什么先做 ResTCN/1D ResNet

ResNet真正有价值的部分是残差连接，而不是把二维图像网络原样套到高炉数据。
一维残差卷积/TCN更适合先捕捉30～240分钟的局部传播、延迟和形状，参数量小于
大型Transformer，更适合当前2,291个独立炉次标签。

### Transformer何时有价值

Transformer适合长依赖和跨时间片交互；TFT通过门控、变量选择和注意力处理多
时域预测，[TFT论文](https://arxiv.org/abs/1912.09363)提供了成熟参考。
PatchTST把序列切成patch以降低注意力成本并扩大回看长度，
[PatchTST论文](https://arxiv.org/abs/2211.14730)还提出自监督预训练。

但当前只有2,291个独立炉次标签，直接从头训练大Transformer风险很高。合理路径
是只在训练月份的无标签分钟历史上做掩码自监督预训练，再在正式炉次标签上微调；
预训练数据也必须遵守时间折边界，不能把测试月份用于预训练。

## 5. 语义神经元应如何定义

建议将概念分三类：

| 类型 | 例子 | 监督方式 |
|---|---|---|
| 可直接计算概念 | 总压差、上下部压差分配、圆周极差、纵向梯度 | 确定性公式 |
| 规则弱标签概念 | 热制度上行、透气性异常、煤气流偏流 | 现有规则引擎分数作弱标签 |
| 隐含工艺概念 | 热储备、炉缸活跃性、料柱稳定性 | 专家标注 + 多任务学习 |

每个概念必须有：

- 中文名称、物理解释和输入范围；
- 时间窗、预期方向和允许交互；
- 概念自身的时间外准确度；
- 对最终Si的增益、消融和方向稳定性；
- 数据不足时的拒绝或降权策略。

概念层可以使用NAM学习单概念非线性曲线；少量明确交互可使用高阶NAM，而不是
重新放开全连接黑箱。[Higher-order NAM](https://arxiv.org/abs/2209.15409)
说明了在保留可解释性的同时加入有限特征交互的途径。

## 6. 下一批固定实验矩阵

所有模型必须使用同一批正式炉次、同一滚动时间折和同一指标。

| 编号 | 模型 | 目的 |
|---|---|---|
| E0 | 当前ExtraTrees | 强基线，任何新模型必须超过它 |
| E1 | 单调/非单调NAM与少量HONAM交互 | 验证可解释概念曲线是否能接近或超过树 |
| E2 | 小型ResTCN/1D ResNet | 验证原始时序形状是否带来稳定增益 |
| E3 | 语义主干 + 有界ResTCN残差 | 验证混合架构的核心价值 |
| E4 | 训练期自监督PatchTST + 语义主干 | 验证长时序预训练价值 |
| E5 | 多任务Si/C/Mn/P/S + 炉渣辅助头 | 验证共享过程表征，前提是标签合同统一 |

必须做的消融：

1. 只用前序炉Si；
2. 只用传感器；
3. 只用语义概念；
4. 只用深度序列；
5. 语义 + 深度无残差限制；
6. 语义 + 有界深度残差；
7. 去掉炉料、炉渣、空间炉身特征分别复测。

## 7. 评估体系

单次70/15/15只保留为快速回归。正式选择使用滚动月份：

```text
训练至M月 -> 验证M+1月 -> 测试M+2月
窗口向前滚动，汇总每一折及最差月份
```

硬指标：

- 代表Si MAE、RMSE、±0.05和±0.10命中；
- 低于0.20、高于0.40的召回率与误报率；
- P10-P90覆盖率、平均宽度和按工况条件覆盖率；
- 正常、热制度上行/下行、气流异常的分层误差；
- 不同试样数、铁罐、班次和数据覆盖率的误差；
- 语义概念准确度、方向翻转率、跨月消融增益；
- 超分布检测率和拒绝预测率。

建议的阶段门不是一个孤立MAE，而是：

- 滚动折MAE中位数比E0至少改善5%；
- 最差月份不得比E0恶化超过5%；
- `±0.05`命中稳定提高且不是以异常召回下降换取；
- 低/高Si召回有足够样本后达到预先约定下限；
- 80%区间覆盖落在75%～85%附近，并同时报告宽度；
- 语义分支方向在多数滚动折稳定。

## 8. 优先级

### P0：先补事实

1. MES真实取样时间；
2. 铁口编号、铁罐和出铁阶段；
3. 精确炉次级炉料化学谱系；
4. 30/60/120/240分钟完整原始序列；
5. 炉渣与铁量的严格时间可见性。

### P1：先改评估

建立滚动月份、尾部Si、工况分层、校准、拒绝预测和消融的统一评估器。

### P2：先做可解释强基线

实现NAM/HONAM概念分支，并逐概念输出响应曲线、方向和跨月稳定性。

### P3：再加小型深度时序

先ResTCN/1D ResNet，证明残差增益后再试训练期自监督PatchTST。

### P4：最后进入影子运行

只把冻结模型的版本化结果提供给MCP；MCP不在线训练。先显示预测、区间、
概念贡献、相似炉次和数据质量，不自动给出调节量。

## 9. 明确不做

- 不直接用当前2,291炉从头训练大型Transformer并以一次测试结果宣布成功；
- 不把树模型重要性解释成生产调节因果关系；
- 不为追求窄区间牺牲覆盖率；
- 不用结果时间冒充取样时间；
- 不让深度残差分支绕过概念层、数据质量门和模型状态门；
- 不在MCP问答请求里训练模型。

## 10. V4/V5 实际迭代补充（2026-07-27）

路线中的“多窗口真实物化”和“滚动月份”已经执行：

- 2,291炉×133点、30/60/120/240分钟统计只读提取完成；
- V5固定选择测试MAE为`0.047882`，`±0.02=31.10%`；
- 滚动月MAE为`0.075529/0.043577/0.060526/0.049776`；
- 复杂窗口特征未稳定超过原V3+历史强基线；
- 留一试样中位数变化均值为`0.035541`，超过`0.02`目标。

因此下一阶段不再以“继续堆树和手工特征”为主。优先顺序调整为：

1. 取得真实取样时间与出铁阶段，建立可重复目标；
2. 建立炉料批次到炉次的精确化学谱系；
3. 固定新的未来月份封存集，停止对当前测试段继续调参；
4. 训练NAM/HONAM概念主干；
5. 仅当ResTCN在全部滚动折稳定降低残差时进入混合架构。
