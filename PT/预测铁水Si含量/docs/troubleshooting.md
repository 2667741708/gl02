# 排错手册

## 模型状态不允许预测

现象：

```text
ModelNotCalibratedError
```

原因：设计配置、退役配置或尚未达到允许推理的状态被用于预测。

处理：不要绕过状态门。完成训练、时间外回测和分布校准，生成新版本配置，并在
模型卡中记录审批结果。

## 缺少标准化特征

现象：

```text
FeatureValidationError: 神经元 ... 缺少特征
```

处理：

1. 核对炉次特征快照的窗口和字段版本；
2. 检查该神经元是否应因数据源不可用而禁用；
3. 不允许用0静默填补未知值；
4. 必要时由数据可信度门拒绝该炉预测。

## 概率区间看似过窄

原因通常是残差标准差只用训练集估计、没有做时间外校准，或忽略了原料谱系和
取样时间不确定性。

处理：在独立时间段重新计算覆盖率，并比较分位数回归、保形区间或分工况残差。

## 回测很好但上线漂移

优先检查：

- 是否随机打散而不是按时间切分；
- 同炉次试样是否跨集合；
- 训练期标准化统计是否泄漏未来；
- 传感器映射和单位是否改变；
- 原料或操作制度是否发生结构变化；
- 当前工况是否超出训练分布。
