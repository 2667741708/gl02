# 正式炉次 Si V3 实验方法

需求编号：`REQ-SI-FORMAL-TRAINING-V3-20260726`

## 1. 固定实验对象

- 代表值任务：正式炉次全部有效试样 Si 中位数；
- 分布任务：正式炉次 `P10/P50/P90`，仅保留至少2个试样的炉次；
- 下一试样任务：因真实取样时间缺失，由标签合同阻止，不参加训练。

## 2. 输入与切分

- 炉次键：MES 正式 `meltno`；
- 特征截止：MES `opentime`，所有传感器时间严格早于截止；
- 候选：133点的当前值、60/120分钟变化量和斜率，加可见的前序炉 Si；
- 覆盖门禁：每炉至少100个当前传感器值；
- 切分：按 `opentime` 固定70%训练、15%验证、15%测试；
- 同一 `meltno` 只出现一次，禁止跨段。

完整标签在预测截止前已全部可见的66炉先排除。本次固定切分为训练1,603炉、
验证344炉、测试344炉。

## 3. 模型与选择

代表值比较：

1. 最近6炉已发布 Si 中位数；
2. 岭回归；
3. ExtraTrees。

只按验证集 MAE 选择，不根据测试集改模型。测试集仅做最后一次报告。

分布任务使用一个 ExtraTrees 多输出模型同时预测 P10/P50/P90，输出后做逐行
排序确保 `P10 <= P50 <= P90`。这只保证数值有序，不代表分布已经校准。

## 4. 区间

代表值的 P10-P90 候选区间使用验证集绝对残差计算80%对称 split-conformal
半径。必须同时报告覆盖率和平均宽度，禁止只报覆盖率。

## 5. 本次结果

实验：
[EXP-SI-V3-FORMAL-001_20260726_222525](../reports/experiments/EXP-SI-V3-FORMAL-001_20260726_222525/)

| 指标 | 结果 |
|---|---:|
| 选中代表值模型 | ExtraTrees |
| 测试 MAE | 0.048851% Si |
| 测试 ±0.05 命中率 | 64.53% |
| 测试 ±0.10 命中率 | 86.05% |
| 80%共形区间半径 | 0.105156% Si |
| 测试区间覆盖率 | 88.08% |
| 测试区间平均宽度 | 0.210311% Si |
| 分布 P50 测试 MAE | 0.048312% Si |
| 预测分布带完整包住实际P10-P90比例 | 23.55% |

代表值点预测已优于前序炉基线，但分布带覆盖偏低且区间仍远大于用户希望的
0.05范围。该结果只能作为正式标签合同下的离线基线，不能升级为在线模型。

## 6. 下一步固定顺序

1. MES补齐真实取样时间、铁口和出铁阶段；
2. 做按月滚动时间外回测，而非只做一次70/15/15切分；
3. 增加30/240分钟窗口统计、炉料谱系和炉渣特征；
4. 对P10/P50/P90使用分位数损失与独立共形校准；
5. 做工艺语义分组、消融、方向稳定性和漂移检查；
6. 通过专家评审后才允许进入只读影子运行。
