# 可解释语义神经元 Si 预测架构

## 1. 数学结构

第 `j` 个神经元使用一组经过训练期统计量标准化的炉次特征：

```text
r_j = Σ(a_ji × x_i)
z_j = sigmoid((r_j - θ_j) / τ_j)
c_j = β_j × (z_j - z_neutral_j)
μ_Si = β_0 + Σ(c_j)
```

- `a_ji`：神经元内部特征系数；
- `θ_j`：响应阈值；
- `τ_j`：平滑尺度，必须大于0；
- `β_j`：神经元对 Si 中心值的贡献系数；
- `z_neutral_j`：中性激活水平，默认0.5；
- `μ_Si`：预测的 Si 中心值。

第一版分布采用经留出集标定的正态残差：

```text
Si ~ Normal(μ_Si, σ_calibrated)
```

正式模型可升级为分位数回归或保序/保形预测区间，但必须保留概率校准测试。

## 2. 模块边界

```text
IMES炉次/化验 ─┐
PostgreSQL传感器 ├─> 炉次对齐与特征快照 ─> 语义神经元 ─> Si分布
炉况诊断快照 ───┤                                  │
原料化学谱系 ───┘                                  ├─> 原因解释
                                                    ├─> 相似炉次
现有规则与工艺边界 ──────────────────────────────────┴─> 受约束建议
```

MCP 只读取已经生成的特征和预测，不在一次问答中训练模型或扫描全量分钟表。

## 3. 时间合同

每条样本必须以炉次为分组键，并同时记录：

- `meltno`；
- 预测发起时刻；
- 目标炉次开口/堵口时刻；
- 每个输入窗口的开始和结束；
- 铁水试样号及结果时间；
- 真实取样时间是否已确认；
- 原料到炉次的谱系方法和置信度；
- 输入数据最大时间不得晚于预测截止时间。

推荐并行构建以下窗口：

- 开铁口前30分钟；
- 开铁口前60分钟；
- 开铁口前120分钟；
- 开铁口前240分钟；
- 前1、3、6炉的炉次序列特征。

旧V1/V2代理数据中化验结果时间不是已确认取样时间，只允许用固定安全滞后做
历史对照。V3正式炉次任务改用`MES opentime`作为整炉预测截止时刻，并严格取
截止前数据；下一试样任务在真实`takesampletime`缺失时直接拒绝训练。

## 4. 目标合同

V3将目标拆成三个互不混用的任务。

整炉代表值：

```text
target__Si_representative
```

定义为同一MES正式`meltno`全部有效Si试样的中位数。

下一试样：

```text
target__next_sample_Si
```

必须按真实`takesampletime`构造“当前试样→下一试样”；结果时间不得参与排序。

整炉分布：

- `target__Si_min/P10/P50/P90/max/std/spread`
- `target__Si_below_020`
- `target__Si_in_020_040`
- `target__Si_above_040`

同炉多试样必须保留原始明细。任何聚合目标不得覆盖或删除原始值。

## 5. 训练和验证

最低比较基线：

1. 上一炉 Si 中位数；
2. 最近3炉移动中位数；
3. 线性/岭回归；
4. CatBoost或LightGBM；
5. 语义神经元模型。

数据切分规则：

- 按炉次分组，同炉试样不得跨训练/测试；
- 按时间顺序切分，禁止随机打散代替未来回测；
- 至少做滚动月份回测；
- 单独报告正常、热制度上行、热制度下行及气流异常区间；
- 训练期均值和尺度只能从训练集计算。

指标：

- MAE、RMSE；
- `±0.05个Si百分点`命中率作为主验收；
- `±0.10个Si百分点`只保留为历史诊断指标；
- 0.20%～0.40%目标带分类准确率；
- 低Si和高Si召回率；
- P10～P90覆盖率及区间宽度；
- 不同月份和炉况下的误差漂移；
- 拒绝预测率和数据覆盖率。

### 高延迟时序三层神经元

130个物理点不直接等同130个已验证神经元。V2固定三层：

1. 单点×多窗口的水平、趋势、波动、记忆、异常和质量微神经元；
2. 压差、比值、A～H空间偏差、垂直梯度和跨变量滞后的物理耦合神经元；
3. 经时间序列交叉拟合与消融保留的工艺语义输出神经元。

默认窗口为30/60/120/240分钟。全部候选只能在训练段筛选，验证和测试段不得
重新选择窗口、滞后或方向。

## 6. 模型状态机

| 状态 | 含义 | 是否允许在线输出 |
|---|---|---|
| `design_only_unfitted` | 只有结构和先验，未标定 | 否 |
| `calibrated_experimental` | 已训练，仅离线实验 | 仅离线 |
| `shadow_validated` | 已通过滚动回测，影子运行 | 是，只读并标实验 |
| `approved_readonly` | 专家评审通过的决策辅助 | 是，只读 |
| `retired` | 已停用 | 否 |

## 7. 建议层边界

预测结果不能直接转换为生产设定值。建议层必须输出：

- 预测时域和Si分布；
- 主要正向/负向神经元贡献；
- 与现有炉况规则是否一致；
- 数据质量和谱系置信度；
- 建议核查项与调整方向；
- 禁止条件、观察项和复核时间；
- 高炉长确认状态。
