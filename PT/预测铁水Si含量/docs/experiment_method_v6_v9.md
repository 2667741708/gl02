# V6～V9 热状态软测量与多模型实验方法

日期：2026-07-27

## 1. 实验目标

本轮不是把“Si 高低”等同于“铁水温度高低”，而是把二者共同受炉缸热状态、
还原动力学、渣铁反应和出铁过程影响的关系拆成可审计的语义特征。当前可训练
目标仍为整炉代表 Si；真实铁水温度和热状态概率只有在取得合格温度标签后才能
训练。

阶段目标：

1. 将传感器观察窗口由 4 小时扩展到 8 小时；
2. 从 133 个物理点构造热输入、煤气利用、透气性、料线、炉体热场、静压力场
   和出铁口温度代理等语义神经元；
3. 仅使用预测截止时刻之前已经发布的前炉化验；
4. 比较直接回归、前炉 Si 残差回归、稳健损失和多模型非负集成；
5. 同时报告 MAE、`±0.02/±0.03/±0.04/±0.05` 命中率及 Si 分布区间。

## 2. 不变数据与切分合同

- 样本身份：MES 正式 `meltno`，不得从试样号猜炉次；
- 预测截止：MES 正式开铁时刻 `opentime`；
- 传感器边界：所有统计均使用 `sensor_ts < opentime`；
- 样本数：2,291 炉，训练/验证/历史测试为 1,603/344/344；
- 物理点：133；
- 历史测试段：2026-06-29 至 2026-07-26；
- 历史测试已被 V5～V9 多轮读取，因此它只能称为“历史测试”，不能继续称为
  全新盲测。后续模型必须使用 2026-07-27 之后的新炉次做前瞻盲测。

窗口合同：

```text
30 / 60 / 120 / 240 / 480 分钟
```

每个窗口保留 `count/mean/std/min/max/slope_per_min/coverage_ratio/range/cv`。
8 小时快照位于
`data/processed/formal_v6_temporal_stats_8h_20260727/`，共 304,703 行、
46 个 Parquet 分片；加载时逐分片重新计算 SHA-256。

## 3. V6 语义神经元

### 3.1 多尺度变化

- 短窗减长窗的均值差、标准化差；
- 斜率加速度与方向一致性；
- 短长窗波动比、极差比；
- 由训练段相关性选择每个变量的优势窗口，验证/测试不得参与窗口选择。

### 3.2 热状态语义组

- 热输入：风量、风温、富氧、喷煤及理论燃烧温度的组合代理；
- 煤气利用：煤气利用率与炉顶温度/压力空间离散；
- 透气性：PI、上/下部压差、总压差及分配一致性；
- 料线：南北料线差和变化方向；
- 静压力场：18 个 A～F 三高度点的圆周离散和纵向梯度；
- 炉体热场：7～16 层炉身温度的层内离散、纵向带差和剖面趋势；
- 出铁口温度：`T_taphole_1/2` 只命名为温度代理，不作为真实铁水温度标签。

### 3.3 前炉化验历史

对 Si/C/Mn/P/S 构造前序炉滞后值、滚动均值、波动和趋势。任一历史化验必须
同时满足：

```text
previous_meltno != current_meltno
result_ts <= current_prediction_cutoff
```

## 4. V7～V9 模型合同

- V7：直接 ExtraTrees、热状态 XGBoost 残差、前炉历史基线的非负集成；
- V8：LightGBM Huber/L1 稳健回归，比较直接目标和相对可见前炉 Si 的残差目标，
  可选 90 天半衰期样本权重，并训练 P10/P50/P90 分布头；
- V9：直接 ExtraTrees、热状态 XGBoost、两种 LightGBM 和历史基线的五分量
  非负单纯形集成。

选择只使用 2026-04、2026-05 扩展窗口与固定 2026-06 验证段。稳健分数为：

```text
robust_mae = mean_month_mae + 0.5 * std_month_mae
```

在稳健 MAE 容差池内，再以平均 `±0.02` 命中率为次目标。所有特征排名均在每个
训练折内部重建。

## 5. 温度联合头门禁

当前 MES 字段 `tappingtemp` 的历史 2# 记录虽存在 9,373 行，但非空真实值为 0。
因此：

- 不训练铁水温度回归头；
- 不训练“热制度上行/正常/热制度下行”概率头；
- 不用 `T_taphole_1/2` 冒充铁水温度；
- 当前 133 点目录未包含冷却壁水温差、流量、热负荷等热损失信号；
- 只有取得带时间戳、炉次、铁口/铁罐/阶段的真实铁水温度，以及冷却热损失和
  炉料谱系后，才进入 Si + 温度 + 热状态联合训练。

## 6. 验收门

当前产物统一保持 `experimental_offline`，不得接 MCP 或生产建议。进入影子运行
至少需要：

1. 新未来月份盲测，不再用 2026-07 历史测试挑模型；
2. 多月 MAE 稳定且显著优于前炉基线；
3. 明确的真实温度标签覆盖率、重复测温一致性和取样/测温时刻；
4. Si 分布 P10-P90 覆盖率按炉况、班次、铁口分层校准；
5. 数据缺失、漂移、版本哈希和回滚测试通过；
6. 专家确认输出只作为只读辅助，不自动写生产设定值。
