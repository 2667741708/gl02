## 维护规则

1. 新的当前合同优先写入 `docs/`；`PT` 保存研究方法、实验报告和专项资料。
2. 带日期的实验报告不改写历史结果；新增结果由本目录 README 或子目录 README 指向。
3. 旧文档需要保留时，在标题后加状态说明和新入口，不把旧命令直接当成当前运维命令。
4. `models/`、`results/`、`reports/experiments/`、`高炉3D模型/work/` 中的重复文件先判断
   是否属于可复现快照；只有确认无审计价值才删除。
5. 连接、模型、端口或生产状态容易变化；使用前以配置、API 和只读探测复核。
