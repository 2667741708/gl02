# 19项时间序列预测统一评测标准

需求编号：`REQ-TS-FORECAST-MULTI-MODEL-BENCHMARK-20260808`

## 固定实验口径

- 目标集合固定为趋势页19项，不得遗漏、重复或用零值代替缺失值。
- 单次推理历史窗口固定为最近480个一分钟点，即8小时；预测窗口固定为未来120个一分钟点，即2小时。
- 每个目标必须同时评测`target_only`和`expert_sparse`两种输入。后者只允许使用该目标的少量特定协变量。
- 模型训练可以使用多个历史窗口，但每个训练样本的可见上下文仍只有截止时刻之前的8小时。
- 未来不可知的传感器变量不得使用实际未来值。只有排程、设定值、日历等预测时已经确定的变量才可作为未来协变量。
- 归一化参数、Q1、Q2、Q3、IQR和误差校准参数只能由训练窗口或预测截止时刻之前的数据计算。
- 缺失数据保留缺失语义。允许有限历史插值或丢弃不完整样本，禁止补零。
- 回测必须按时间顺序切分，禁止随机打乱后切分；至少覆盖不同班次和工况阶段。
- 当前Chronos-2、LastValue必须始终作为对照组。候选模型不得只与另一个复杂模型比较。

## 不可删减评测指标

| 维度 | 固定字段 | 定义与判读 |
|---|---|---|
| 原始误差 | `mae`、`rmse` | 原始单位误差，越低越好 |
| 统一量纲 | `iqr_nmae` | `MAE / max(Q3-Q1, abs(Q2)*1%, 1e-6)`，越低越好 |
| 基线优势 | `mase` | MAE除以历史一步持久性误差；小于1才优于朴素预测 |
| 振幅保持 | `std_ratio` | `STD(p50) / STD(truth)`；用于识别预测过度平滑或过度振荡 |
| 短时动态 | `diff_std_ratio` | 预测与真实一阶差分STD之比 |
| 方向判断 | `direction_accuracy` | 包含预测起点后的逐分钟涨跌方向一致率 |
| 区间覆盖 | `coverage_p10_p90` | p10-p90覆盖率，名义目标为80% |
| 分位数误差 | `pinball_p10`、`pinball_p50`、`pinball_p90` | 分位数损失，越低越好 |
| 综合概率误差 | `wis_80` | 80%中心区间的加权区间分数，越低越好 |
| 分时段误差 | `mae_m00_30`、`mae_m31_60`、`mae_m61_120` | 检查预测随时间跨度的退化 |
| 工程性能 | `train_seconds`、`latency_ms`、`model_bytes`、`peak_gpu_mb`、`peak_ram_mb` | 判断220.12常驻部署代价 |
| 数据质量 | `truth_points`、`missing_ratio`、`failed_windows` | 防止用缺失或失败样本美化结果 |

`std_ratio`和`diff_std_ratio`不设脱离业务的硬性冠军阈值，但必须与MAE同时查看。若MAE较低而两项长期明显小于1，模型应标记为`underdispersed`，不得仅凭MAE上线。

## 固定比较方式

- 每个变量、每个模型、每个输入方案分别给出指标，不允许只给19项平均值。
- 同时给出宏平均和按有效点数加权平均。
- 输出0至30、31至60、61至120分钟三个预测段。
- 给出相对LastValue和当前Chronos-2的胜负数量。
- 对p10-p90覆盖不足、STD坍塌、预测失败、缺失数据敏感分别列出变量清单。
- 模型入选必须在误差、动态性、概率区间、稳定性和资源五类指标中综合判断。

## 模型候选顺序

第一阶段固定比较：`LastValue`、`LinearDrift`、`RidgeDelta`、当前`Chronos-2`。

第二阶段按同一接口接入：`TSMixerx`、`IBM TTM`、`TimesFM 2.5`、`PatchTST`。

第三阶段候选：`Moirai 2.0`、`N-HiTS`、`Chronos-Bolt`、`MOMENT`以及第一、二阶段优胜模型的加权集成。

## 服务边界

- 生产Chronos保持端口`8777`。
- 多模型旁路固定端口`8778`，不得被趋势页生产链路默认调用。
- 8778统一端点为`GET /api/timeseries/status`、`GET /api/timeseries/models`和`POST /api/timeseries/predict`。
- 为复用现有回测工具，8778同时兼容`GET /api/chronos/status`和`POST /api/chronos/predict`。
- 未完成回测和人工确认前，旁路结果只能进入实验报告，不得覆盖生产预测。

## 统一排行榜合同（2026-08-11）

- 排行榜固定使用所有候选模型共同具备的完整切点和相同19项目标；不完整切点不得只对单个模型保留。
- 分段误差必须按每个窗口的历史IQR尺度归一化，输出`nmae_m00_30`、`nmae_m31_60`、`nmae_m61_120`。
- WIS同时输出跨变量可比的`iqr_nwis_80`；原始`wis_80`继续保留，不得删除。
- `std_ratio`和`diff_std_ratio`按与1的对称对数距离排名，避免把超过1的过度振荡误判为越大越好。
- 综合分由透明固定权重构成：IQR-NMAE 25%、IQR-NWIS 20%、三个预测段各10%、方向准确率10%、覆盖偏差5%、STD距离5%、差分STD距离5%。综合分越低越好。
- 除综合排名外，必须分别给出点误差、概率预测、方向、振幅、分钟动态、覆盖率及三个预测段的冠军。
- 当前实现入口为`tools/timeseries_leaderboard.py`，固定输出JSON、CSV和Markdown；8778只读接口为`GET /api/timeseries/leaderboard`。
- 排行榜是实验决策证据，不构成自动切换8777、8778默认模型或生产趋势页的授权。
