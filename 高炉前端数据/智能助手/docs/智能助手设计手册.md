# 智能助手设计手册

## 定位

8092 智能助手面向高炉长和值班人员，首要目标是帮助他们在不被界面打扰的情况下提出问题、插入必要资料、获得可追溯的诊断与调控建议。界面应保持克制、稳定、可扫读，不能把报表库和上下文细节强行堆到聊天主区。

## 页面骨架

- 左侧是工作区：新对话、搜索、项目、项目下对话和最近对话。
- 中间是对话主区：只承载当前问题、助手回复、流式生成状态和输入框。
- 右侧是来源与报表面板：按需要展开，用于选择报表、文件、默认上下文和打开方式。

主聊天区永远优先。报表管理、项目文件、来源筛选等都应该是辅助面板或独立页面，不抢夺高炉长对炉况判断的注意力。

## 项目设计

项目类似 GPT/Codex 的 Projects，是一组对话、报表、文件和默认上下文的工作区。

- 未进入项目时，智能助手仍可正常问答。
- 进入项目后，新对话归属该项目。
- 项目可以新建，也可以绑定系统允许目录下的已有项目或报表文件夹。
- 项目资料默认只是候选来源，不自动塞入模型上下文。
- 项目必须支持固定、取消固定、重命名、归档、移除登记和在资源管理器中打开。

## 对话设计

对话是项目内的独立分析线索。

- 对话可右键打开菜单，也可通过“更多”按钮打开菜单。
- 对话菜单至少包含置顶/取消置顶、重命名、归档、标记未读/已读、复制会话 ID、复制深度链接。
- 置顶、归档、未读和标题状态都必须持久化，刷新后保持一致。
- 归档默认从活跃列表隐藏，不删除历史消息。

## 报表与文件

报表选择器分两层理解：一层是上传或绑定的文件类型，一层是业务报表类型。

- 文件类型：Word、Markdown、PDF、Excel/CSV、其他。
- 报表类型：时报、日报、周报、月报、临时报。
- 层级浏览优先按年、月、周、日、小时组织。
- Word 主要用于现场阅读、批注和打印。
- Markdown 是模型读取、系统改写和版本维护的主内容。
- 只有 Word 没有 Markdown 时，应先生成可读 Markdown 副本，再进入模型上下文。

## 报表预览页面

报表不直接写死在智能问答界面里，而是走“报表模板中心 + 预览渲染器 + 插入适配器”。

- 报表预览是独立页面，不挤占智能助手聊天主界面。
- 页面左侧展示报表文件夹树，按 `年 / 月 / 周 / 日 / 时` 分层。
- 文件夹树的任意节点都可以被选中作为当前浏览范围：选年份看全年，选月份看当月，选周看该周，选日期看当天，选小时看该小时。
- 选中的文件夹可直接作为项目打开，项目对话继承该文件夹下的报表与文件作为候选资料，但仍不自动塞入模型上下文。
- 页面中间是模板中心，支持时报、日报、周报、月报和时间范围选择。
- 页面右侧是预览渲染器，优先用后端返回的 `content_json` 渲染，不直接信任任意 HTML。
- 保存报表时同时生成 Markdown 和 Word；Markdown 是模型读取与系统改写主版本，Word 是现场阅读、批注、打印和人工留痕版本。
- 插入到问答助手时，前端展示报表卡片或上下文篮标签，后端根据 `report_instance_id` / `period_report_id` 查询完整报表，再拼入模型上下文。

## 报表存储层级

默认根目录是 `高炉前端数据/data/reports/`。新的报表实例按年月周日时的文件夹层级落盘：

- 时报：`YYYY/MM/Wxx/DD/HH/时报/`
- 日报：`YYYY/MM/Wxx/DD/日报/`
- 周报：`YYYY/MM/Wxx/周报/`
- 月报：`YYYY/MM/月报/`

旧结构 `YYYY/MM/时报/DD/HH/`、`YYYY/MM/日报/DD/`、`YYYY/MM/周报/Wxx/` 仍作为历史文件兼容读取；界面展示时统一折叠成 `年 → 月 → 周 → 日 → 时`。

每个报表实例至少包含：

- `.md`：可编辑、可进入模型上下文的主版本。
- `.docx`：现场人员可用 Office/WPS 阅读和修改的版本。
- SQLite 记录：保存模板、时间范围、结构化 JSON、预览内容、Markdown 路径、Word 路径和插入引用。

## 上下文篮

智能助手不会自动塞报表。高炉长每次发送前都应能看到本轮实际传入的资料。

- 每份资料以轻量标签进入上下文篮。
- 标签支持摘要、全文、片段三种传入模式。
- 发送前可打开“编辑传入内容”，人工删改、补充现场备注。
- 取消固定或移除上下文只解除本轮或默认关联，不删除源文件。

## 文件打开方式

文件和文件夹只允许在系统白名单根目录下操作，默认根目录是 `高炉前端数据/data/projects/` 和 `高炉前端数据/data/reports/`。

- 文件项提供打开、在资源管理器中定位、复制路径。
- Word、Excel、PDF 等现场文件可提供 Office、WPS、系统默认方式。
- 如果 Office 或 WPS 不可用，回退到系统默认关联。
- 不默认扫描任意 Windows 路径；如需扩大范围，必须增加管理员白名单配置。

## 流式输出

智能助手调用 `业务模型` 时，应优先使用流式输出。

- 后端请求 Ollama 必须显式传入 `stream:true` 和 `think:false`。
- 前端收到 delta 后实时更新助手气泡。
- 生成结束后，后端只持久化清洗后的完整最终回答。
- 错误应显示给用户，但不要写入空助手消息。

## 视觉原则

- 不做营销式大卡片，不把工具说明写成页面正文。
- 操作按钮使用熟悉图标或短文本，危险操作要二次确认。
- 当前项目、当前对话、已选上下文需要清楚，但不喧宾夺主。
- 高炉长常用动作应在一到两步内完成：新建对话、插入报表、查看来源、打开文件、归档线索。
