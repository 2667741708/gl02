## 使用说明

这些示例面向 8092 智能助手的统一知识库/向量库检索层，用来帮助现场人员、工艺工程师和演示人员快速学会“怎么问更容易命中正确知识”。

当前向量库覆盖 01-26 篇高炉知识文档，主要包括基础机理、工况诊断、参数协同和汇报表达四类知识。案例库尚未结构化入库，因此“案例/复盘”类问题当前会优先召回相近的诊断知识或参数知识，不能等同于真实事故案例检索。

如果用于自动化评测，请优先使用机器可跑测试集：

```text
高炉前端数据/智能助手/tests/bf_rag_eval_v2_queries.jsonl
```

评测集说明见：

```text
高炉前端数据/智能助手/docs/高炉向量库RAG评测集说明_v2.md
```

建议提问时尽量同时给出：

- 现象：如压差升高、风量下降、顶温偏散、铁水硅波动。
- 目标：如判断原因、稳妥调参、写日报、做汇报。
- 边界：如只做初判、不要下操作指令、不要补充未提供数值。
- 时间或对象：如本班、近两小时、2 号炉、GL02。

## 推荐提问模板

诊断类：

```text
近【时间范围】，【现象1】、【现象2】，请做工况初判，并说明依据、风险和需要补充的数据。
```

参数优化类：

```text
当前目标是【提高/降低/稳定某参数】，已知【当前现象或限制条件】，请给出稳妥建议，说明先核查什么、风险是什么。
```

报告类：

```text
请把以下现象整理成【班报/日报/领导汇报】，要求不要补充未提供数值，原因只做初步判断。
```

案例/复盘类：

```text
有没有类似【异常现象】的经验可以参考？请说明相似点、差异点、适用边界和后续关注。
```

## 当前测试结论摘要

在 220.12 上使用 `bf_unified_vectors.sqlite3` 进行 100 条基准问题测试时：

- 严格通过率：66.0%
- 意图识别命中率：75.0%
- Top1 类别命中率：81.0%
- Top3 类别命中率：89.0%
- 平均检索耗时：84.5 ms
- 最大检索耗时：1429.3 ms，主要来自首条冷启动

当前最容易失败的问法集中在两类：

- 参数协同口语问法，例如“风温富氧喷煤怎么协调”“燃料比想降一点咋弄稳妥”。
- 顶温/煤气流/偏行类诊断问法，例如“顶温乱，煤气是不是跑偏了”。

后续优化应优先增强这两类的意图识别、术语扩展和 query rewrite。
