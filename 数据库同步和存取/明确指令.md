# 用户明确指令：220.12 数据库同步和存取

确认日期：2026-05-09

用户要求：

1. 在项目下保留一个独立文件夹，文件夹名固定为 `数据库同步和存取`。
2. 该文件夹用于实现从备份数采服务器 `10.22.181.243:8889` 同步历史数据和持续获取最新实时数据，并进行本地/220.12 数据库存储积累。
3. 同步范围仅限本文件夹 `config/点位清单.tsv` 中列出的变量，以及用户明确给出的炉体温度 7-16 层 A-H 范围点；不额外加入其它变量。
4. 需要同步 pSpace `HisReadProcessed` 的 1min 均值，口径为 `PS_HIS_AVERAGE`、`interval_seconds=60`。
5. `GasUtil` 位于跨子树 `\冀南钢铁\SIO\CC\GF2\SIO_CC_GF2_T0115`；`CO_top`、`CO2_top`、`H2_top` 位于同一跨子树的 `T0112/T0113/T0111`；三点必须按白名单明确读取，不能被 GL02 根节点过滤掉。
6. `T_top` 是 `T_top_A-D` 四点平均派生量，默认查询时计算，不重复入库。
7. 目标是让 220.12 服务器保存 243 中已存的历史数据和持续新增数据；后续模型访问 220.12 本地数据库，而不是每次直接访问 243，以便更快、更方便。
8. 必须实现一个查询程序，用于从 220.12 的数据库按变量名和任意历史时间范围获取数据。
9. 对 243/244 数采服务器只做只读采集，不修改任何生产配置、服务、文件或数据。
